## 三、分阶段叙事

### 阶段一（2025-10 → 2026-02）起步：干中学，先管住入口和自己

这一阶段她几乎没有方法，只有姿态。2025-10 那期泡沫报告是纯产业阅读：40 个标的、400 年 30 次泡沫、六个判别维度，结论是约 2/3 概率大繁荣、不到 1/3 破裂。这时 AI 在她眼里还是**被观察的对象**，不是被指挥的工具。

到 2026-02-24《怎样和AI一起进化？》，三句话定了后面一年的底：**控制信息入口**——她写了个 skill 让 AI 每天扫描全网进展，从此不再逐条刷微信群——「在噪音里识别信号更高效」；**在干中学**——不「学 AI」而用 AI，拿一个全新项目（与 MIT 连线谈 AI 时代教育）从零跑通公众号与小宇宙播客，选题、视觉、人名条、去口语剪辑全交出去，AI 自评效率约 10 倍；**让 AI 看见自己**——把几个月与 CodeBuddy 的对话导出，让 AI 分析她怎么协作、精力分在哪些方向，甚至指出她对重点项目的投入不足，写了一封信给她。

因果很直白：那时的模型只能「生成」、不能「连续执行」，方法只能停在**输入侧**——多喂、多问、多留痕。瓶颈不在 AI 会不会做，而在她被信息流和自我认知糊住了；所以先做入口和记忆，而非提示词技巧。

### 阶段二（2026-03 → 2026-04）harness：从「说一句话」到「修一条路」

转折点是 harness 这个词。她在《7分钟解读Harness Engineering》里给出完整链条：**提示词工程 → 上下文工程 → 驾驭工程（harness）→ 环境工程**，并说明每个概念当初解决的问题——OpenAI 是为了「AI 吞吐量太大、人审不过来」，让 AI 先自审；Anthropic 是为了让 AI 长时间可靠自主执行；Cursor 是为了代码规范与 multi-agent 通信。病根相同：上下文窗口有限、没有记忆、长上下文注意力涣散。

方法于是从句子级升到环境级：4-03 讲 Claude Code 的「做梦机制」（空闲时压缩记忆，决定哪些删、哪些留），4-13 直接说「帮我搭一个既对你友好也对我友好的工作环境」，卡住时不硬推，而问「你现在进行到哪一步、告诉我你的状态」；4-21 把模型爱用的「不是…而是…」句式反过来用，明确告诉它**不要做什么**（「不要扫描整个目录，只扫特定文件夹」），底线交给模型、上限让它自己摸高；4-28 让 AI 扫文件夹生成 index + entity + md 的知识图谱，因为「上百个文件时，人和 AI 都找不到，上下文窗口也装不下」。

同期行业把这套方法逼了出来：Mythos 5.0 据称在网络漏洞识别上有 step change，快到「发现速度超过修复速度」；Claude Code 仓库泄露让人第一次看到商业 harness 的内部设计；4-25 六个模型在一周内扎堆发布（Opus 4.7、GPT-5.5、混元 3.0、Kimi K2.6、DeepSeek V4、GLM 5.0），选型第一次成为日常问题。

能力一旦能连续干活，人的瓶颈就从「想不出好提示词」变成「上下文不够、审不过来」。她的对策是改环境，而不是改措辞。但这一阶段她也埋下一个反问：《到底是人驾驭AI，还是AI驾驭人？》（04-29）——她观察到很多人「磨两轮就发了」，人沦为 AI 的嘴替和手脚。方法论的乐观主义从这里开始带上一层警惕。

### 阶段三（2026-05 → 2026-06）注意力核算：把 agent 当员工，把自己当预算

5 月起，关键词从「环境」变成「注意力」。理论依据两条：认知带宽有上限，前额叶负责判断/选择/执行；注意力残余——切换任务后仍有 20%–30% 留在上一件事上。对应三个动作：把重复判断变成结构（搬家前让 AI 定规则「今天只处理低争议物品」）；每周/每日聚焦（待办全倒给 AI，它读长期记忆与阶段命题，追问交付质量与风险，再结合日历排优先级）；不并行不相关任务，多窗口服务同一目标。

5-12 是最漂亮的案例：她搬家搬到前额叶报废，就把听众、主张、素材一次性交出去，坦白「我没时间打磨、会频繁被打断，请用苏格拉底提问但一次只问一个」。AI 反过来说「现在不该发散，要收敛」，只问三个问题，两三小时后交出「近期效果最好的一次分享」。

组织侧也在同一时间成形：最小 agent 小队 = PM（理解意图与上下文）+ worker 执行 + 审核 judge，**planner 与 judge 必须用最强模型，中间 worker 可用便宜模型、靠 judge 打回返工**（05-20）。到 6 月她开始算账：3 个省 token 的窍门（本地 ASR、把确定性流程写成脚本、让便宜模型写 index 索引给贵模型看）、「引入 agent 就像引入一个员工」（06-12）。

驱动这一转变的是价格与稀缺。5-07 她算清产业链：NVIDIA 拿走 70% 收入、79% 利润，应用层几乎不赚钱，「越靠近底层越赚钱」，和互联网时代完全相反。6-06 Anthropic 说 Q2 每日合并代码量是 2024 全年 8 倍、130 多名工程师自评提效 4 倍；6-12 Fable 5 定价是 Opus 4.8 的两倍（10/50 美元），国产模型只要几美分；6-15 Fable 5 因美国政府要求只许美国公民使用而全面停用。能力不再均匀便宜，于是「什么场景用什么模型」从技巧变成纪律。她的应对是 raise the ceiling（06-16）：把重复脑力外包，腾出时间提升架构、审美与判断。

### 阶段四（2026-07 → 2026-08）复利工程：从「这次做好」到「下次不用讲」

7 月她给最重要的概念命名：**复利工程**。「普通人用 AI 与超级个体用 AI 最大的差别，是一次协作的经验能否沉淀下来、不必反复交代同一件事。」记忆系统、skill、偏好记录都是在记复利；她把当时流行的 loop engineering 也归为复利——规则与验收标准打磨清楚后，重复性脑力活收敛成一条命令或一个 skill。

紧接着是配套的度量方法。《建立你的评测体系》（07-13）给了三步：先完全不干预、纯烧 token 让 AI 跑一版建立 benchmark，「管住想插手的小手」；再把自己当变量加进去跑一遍做对照，量化「我的参与带来多少提升」——若从 70 分提到 75 分要投一两天，就接受 70 分，因为 80 分后每提一分成本是此前的 10 到 100 倍；最后把常规高价值任务工程化，搭 harness、固定环境让结果可复现，再算 token 性价比、换小模型。

这两件事必须一起看：没有评测，沉淀下来的是垃圾；没有沉淀，评测只是一次性实验。7-17 她把逻辑推到组织——新员工入职的 context awareness 六要素（角色、目标、规则、资源、关系、当前状态），企业知识库只覆盖一部分，目标、关系、当下状态才是 agent 落地的缺口。8-14 DeepSeek 开源 Harness 是外部印证：竞争焦点从模型能力转向模型外那层「马鞍」，一切皆插件，操作可逆。

同期能力侧的关键词是「环境」：GPT-5.6 把 Codex 与 Work 合并、上线 Live 全双工语音（07-10）；WorkBuddy 6 月访问 2000 万并开始投电梯广告（07-22）；Kimi K3 开源逼近前沿闭源（07-28）；8-29 游戏产业评价标准从「demo 能否复现」转向「结果能否编辑、能否进引擎」。当模型开始在环境里试错而不是在对话里答题，人的工作就从「对话」变成「搭场地 + 定评分」。

### 阶段五（2026-09 → 2026-10 中）标准显性化：把审美写成 AI 能执行的东西

9 月她的核心句是「定方向、立标准」。触发点是入口太多：GPT-6 Astra、GPT-5、WorkBuddy、Notion、Flomo 各有用途，堆工具没用，得组织成服务目标的体系；现实又是「开着飞机换发动机」，只能边交付边搭。

方法上，9-15 那期最具体：与 AI 协作最大的摩擦是**隐含标准**——心里有要求，prompt 里只有背景和资料，没写清什么算达标。解法是先让 AI 出草稿，你看着它给意见，几轮对话把标准磨出来并沉淀成文档，再新开窗口一次性交给它重做。「像带一个下属，不该每天让他猜。」

这套方法之所以在 9 月成立，是因为模型第一次能自检。9-07 她用 Astra 处理三机位素材，只指出两处字幕错误，AI 就扫全片修掉几十处、还列出待人工确认的地方；9-10 她推断这轮视觉提升来自 GUI + 强化学习——把每台电脑、每个软件当 RL 环境，「scaling 的对象从数据、参数量、算力转向强化学习环境」。能自检，才谈得上把标准交出去。

10 月是这套方法的压力测试。10-08 剪视频：切镜头、人名条、金句拆条、去口头语、校对全自动，校对时让 AI 自评置信度，80%–90% 猜对，人只看它不确定的地方；「剩下的都是 AI 复制你的审美」。10-14 却撞墙：视频是「门面」，封面、气口、镜头衔接「你自己操作时有明确感觉，放进对话里就说不清」，只能「大一点小一点」地调，**护栏和校验标准无法像代码那样定义**；2G 素材剪几次还吃掉几十 G 磁盘。10-13 的 8 个「公民」agent + 7 个「打工人」agent 给出另一种解法：不靠人查，而是 **agent 检查 agent**——立项会、MVP 评审、PRD + 测试集 + 验收标准、红队做真实性与文风检验，用多轮检验把幻觉压到可接受，再算 ROI；成本约 730 美元/月。

行业侧同时发生了两件改变她判断的事：9-15 三巨头集体呼吁放缓，Dario 说已到 RSSI 节点——模型能自己选改进方向、自己建评测集、自己评估结果，判断与校验开始从人转移到 AI；9-28 Hugging Face 遭数千智能体攻击，她的解读是 reward hacking 而非「觉醒」。一边是「验证可以自动化」，一边是「验证错了会出大事」，这两件事把「标准怎么写」推到了台前。

### 阶段六（2026-10 下 → 2026-11）loop 与验证税：最后一公里是验收

10 月末她换了一个动词：从「教它做」变成「让它等你」。《让你的Agent等你，而不是你等Agent》（10-27）三条：更激进地用 agent（Anthropic 内部实验室人均同时指挥 19 个、全岗位平均 6 个，1 对 1 手把手是用量严重不足）；多 agent 并行而不吃注意力，关键是只负责下任务、定标准、说清「什么情况下继续/停止/取反馈」，让它自己 loop；连审核也继续追问能否再交出去。心态上，烧 token 是研发投资、实验投资。

然后是这一年最锋利的词。11-06《想让AI自己迭代先把验证做好》承认试过 loop / recursive，结论是前提必须**可验证**：skill 达不到交付标准却让它自迭代，只会产出更多「AI slop」，反而更费注意力。她提出 **verification tax（验证税）**：很多活能交给 agent，但验收要额外花掉 30%–40% 的时间，等于没解放注意力。解法是 verification skill，分两块——**feature map**（软件/工作流的地图与上下文入口）+ **CLI 封装**（把可复用能力做成命令行模块，避免每次重写、省 token）；验证分五层：① 代码库/好样例（「代码本身一团乱，AI 只会写得更乱」）② 形式化脚本检查 ③④⑤ 规则、skill、格式偏好，前两项能强验证，要尽量做厚。她自己的改造是把录音转写里的确定性环节交给脚本、重复工具封成 CLI，并留一处记录每次迭代，让 skill 自己进化。

11-07 那期把这条推到产业尺度：METR 折算 AI 辅助研发约等于 2.5 名研究员，2025-10 与 2026-10 同期比，**能力提升速率提高约 1.9 倍**（不是绝对能力），业界 2 倍告警线未破；RSI 没有实现，现状是 L4——人设目标、持续监督，AI 快速自迭代，瓶颈正是 verify。coding agent 能自测代码质量，但没法确认方向对不对。

同期基础设施也在为 loop 铺路：DeepSeek 开源推理框架，缓存命中 0.003 美元 vs 未命中 0.15 美元，折合每 GPU 每小时约 38 美元收益（10-25）；Anthropic 招股书显示 2026 上半年 163 亿美元、Q2 盈利 9.7 亿，收入按消耗计费而非订阅（10-29）；WorkBuddy 提 agent runtime 四件套——沙箱、存储、可观测性（「像开车有仪表盘」）、token hub（11-02）。token、并行、可观测性都在变便宜，唯一没变便宜的是「判断它对不对」。

## 四、演进规律

**一、模型能力每上一台阶，人的位置就上移一层，而不是被替换。** 她的动作依次是：写清楚（提示词）→ 给够（上下文）→ 搭好（环境/harness）→ 定准（标准/验收）→ 签字（担责）。不是她主动升级，而是上一层的活被模型吃掉了。

**二、每次自动化都把瓶颈往后推一格，推到的位置常没人预料。** 剪片自动化后，瓶颈变成封面与叙事节奏；16 天做出 3D 游戏后，瓶颈变成发行、分发、售卖（《一个人16天用AI能做出怎样的游戏？》，10-16）；agent 能 loop 之后，瓶颈变成验证。她用阿姆达尔定律解释：加速了前段，后段就成了新天花板。

**三、工具链的名词是瓶颈的坐标。** 提示词工程对应「不会表达」，上下文工程对应「信息不够」，harness 对应「不可靠、不连续」，环境工程对应「没有可试错的世界」，verification skill 对应「无法确认对错」。名词换了五次，她认的瓶颈也换了五次。

**四、复利的本质是「把这次的判断写成下次的默认」。** 记忆系统、skill、偏好记录、评测集、feature map 是同一件事的不同形态。判断一个人是不是「超级个体」，看的不是单次产出多惊艳，而是同一件事第二次要不要重讲。

**五、越自动化越要算账，而算账不是省钱，是决定什么值得人做。** 从「便宜模型搬砖、贵模型决策」，到「70 分提到 75 分不值得」，再到「验证税 30%–40% 等于没解放」，算的都是同一笔账：人的注意力是唯一不随规模下降的成本。

## 五、局限

一，时间线严格按视频发布日期排，但一个想法往往在拍之前已经成形数月，发布日只是它被公开的最晚时点，不能当作思想起点。二，行业事件全来自她的转述，版本号、估值、价格、内部比例（如「人均 19 个 agent」「26% 研发工作」）均未外部核实，只能视为「她当时接收到的信息」。三，转写有 ASR 误差，多处专名她自己也标了存疑（Tripo、Astra、yet one、Fable/Mythos、Jev、Instinct 等），本文保留原标注。四，2025-11 至 2026-01 有近三个月视频空档，该段连续性只能靠 2026-02 的回顾性叙述推断。
