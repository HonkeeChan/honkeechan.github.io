**1️⃣ Mercury 3：扩散 LLM 比 GPT-6 Luna 快 8 倍，SWE-Bench 反超，价格约其一半**

Inception Labs（斯坦福教授 Stefano Ermon 联合创办）10 月 19 日发布 Mercury 3：参数规模比第一代扩大 40 多倍，输出吞吐仍维持 1068 Token/s，最高约为 GPT-6 Luna（约 130 Token/s）的 8 倍、Claude Haiku 5.5（约 240）的 4 倍多。官方同档位对比中，GPQA Diamond 得 89.23（Luna 86.36、Haiku 5.5 84.51）；真实工程任务差距更大——SWE-Bench Atlas 51.08（两者 33.33 / 32.26），IFBench 76.84。上下文扩到 100 万 Token，首发价输入 $0.10、输出 $0.35 每百万 Token，正式标价 $0.20 / $0.70。机制上它是扩散式并行生成：同时预测多个位置、再迭代去噪，一次前向更新一批 Token，绕开自回归的逐 Token 串行瓶颈。生态侧，浏览器 Agent 公司 TinyFish 已把 Mercury 3 接入生产代理系统，Mind2Web 50 项真实网站导航任务完成 25 项（50%），高于 GPT-6.1 Sol，且 Token 消耗与执行步骤与对手相当。⚠️ 基准与速度均为官方自报、未附第三方复现；「快 8 倍」是特定 NVIDIA GPU 上的吞吐对比，端到端 Agent 时延还受工具调用与页面等待支配。

**2️⃣ 79% 企业 GPU 一半时间闲置，91% 的新算力投入拿不出经财务审核的 ROI**

VentureBeat Intelligence 汇总 2026 年 7、8、9 月三轮 VB Pulse 调研（385 名来自百人以上机构的受访者）：79% 表示自家 GPU 算力至少一半时间完全闲置，三个月稳定在 77%–81%；更反直觉的是，这批利用率不足 50% 的企业中 70% 仍计划 12 个月内引入、扩充或更换 AI 计算平台。钱流向也很清楚：计划采购者 90% 投向公有云与模型 API 服务商，仅 8% 考虑扩建本地私有集群——自建算力成沉没资产，闭源前沿模型的 API 账单却在吞噬预算（《财富》曾报道 Uber CTO 用「AI 使用排行榜」鼓励内部使用，几个月便花光 2026 全年 AI 预算）。财务侧同样空转：64 名计划采用新平台的受访者中 58 人（91%）拿不出经财务部门审核的 ROI。压力还会往上走——Gartner 预测 2028 年单个 Agent 工作流的推理成本将升至 5 倍以上，因为完成任务的 Token 消耗增速快过单价下降；NVIDIA 工程师测算 Claude Code 会话中后续请求 85%–97% 的上下文可缓存复用，而 Anthropic 的缓存读取价可低至常规输入价的 1/40–1/10。⚠️ 样本为研究机构自采调研（385 人）、非审计数据，且部分闲置可能出于峰值预留。

**3️⃣ 清华李一鸣团队 PrismWAM：RoboTwin 2.0 登顶，RoboDoctor 把执行诊断做到 RoboDojo 首位**

厘清智能创始人、清华大学人工智能学院李一鸣团队同期发布两项 Physical AI 成果，主线是「Scaling Physics 而非 Scaling Semantics」。模型侧 PrismWAM 把语义上下文与物理状态解耦，走 Semantic Planning（读 RGB 判意图）→ Physical Rollout（用深度表征预测几何与状态演化）→ Executable Action（动作模块不直接读 RGB）三级链路；在双臂基准 RoboTwin 2.0（50 项任务、背景/光照/杂物/桌面高度/指令五维随机化）上，不做动作数据预训练即取得平均成功率 83.67%，官方榜第一（截至 10 月 23 日），高难度 Clean-to-Random 为 75.5%。系统侧 RoboDoctor 用执行反馈做诊断、纠错与经验积累，覆盖 RoboDojo 全部 54 项任务得 57.1 分，居当前对比首位。⚠️ 两个分数均为团队自报榜单、未附第三方复现；「世界动作模型」品类近两周已推过 OpenWAM、UniWAM、LoopWAM 三条，本次新增点是语义/物理解耦链路与执行侧自我诊断闭环，故列「值得看」不进必读。

**4️⃣ TorchTPU 技术报告：PyTorch 原生跑 TPU，4917 个 HF 模型 98% 跑通**

PyTorch Conference 2026 上谷歌开源 TorchTPU：基于 PyTorch 预留的 PrivateUse1 接口注册为 C++ 后端，运行时不再依赖 JAX，TPU 与 GPU/CPU 并列成为原生设备，Hugging Face Transformers v5 里传一个 `device_map="tpu"` 即可部署；由谷歌与 Meta 联合开发，vLLM、SGLang、Ray、TorchTitan 同步接入。即时执行分 Strict / Debug / DeferAndFuse 三档，DeferAndFuse 攒算子后融合，比 Strict 快 50% 以上；`torch.compile` 走 StableHLO + XLA（刻意不走 Inductor，因为 Triton 难移植到 TPU）。覆盖面上，HF 下载量最高的约 5000 个模型中 4917 个可用，98% 跑通不崩溃、657 个代表架构里 97% 输出与 GPU 数值一致；30B 模型单颗 TPU v7 预填充 2.57 万 Token/s、MFU 59%，4 颗训练 MFU 38%。官方文档称 TorchTPU 将取代 PyTorch/XLA。⚠️ 该发布 10-22 早报已推（8000 颗 Ironwood 验证那条），本次为 23 页技术报告细节，按同产品线第 2 次降档。

**5️⃣ Scinetics ScienceRSI：4B 专家迁到 27B，七项基准均分 87.3%→94.0%**

Scinetics 联合复旦大学、中科大、港科大发布技术报告 ScienceRSI，把科学能力训练拆成专业化→验证→迁移→复用：先训定量计算、符号推导、机制解释、证据判断四类紧凑专家，再用一组可检查的要求（计算对不对、机制是否成立、结论有无证据）筛选「谁的贡献真的优于当前回答」，最后把通过筛选的反馈注入目标模型。结果：4B→4B 科学推理均分 55.0%（GRPO 53.0），领域科学 59.3%（+3.3 个百分点）；4B→8B 分别 +1.9 / +2.1；8B 专家迁到 Qwen3.5-27B 后七项基准等权均分由 87.3% 升至 94.0%，ChemBench 87.2→95.5、RaR-Med 82.9→91.7。最说明问题的是消融：去掉专家贡献的验证环节，55.0 掉到 50.6；把同样覆盖量的反馈随机移到回答其他位置，科学推理与领域科学分别降 6.3 / 12.1 个百分点；而「任务奖励 + 密集专家监督」（GRPO+MOPD）只有 50.1%，反低于纯 GRPO —— 专家信号不经筛选会帮倒忙。ScienceRSI-8b 权重已上 Hugging Face。⚠️ 预印本（preprints.org）未经同行评审，分数为团队自测。

**6️⃣ 奥特曼内部预判 AI 三种终局：全球监管、实验室合并、或一家独大瘫痪对手 GPU**

《The Information》报道，奥特曼在内部员工会议上给出 AI 竞赛的三种终局：① 建立类似国际原子能机构（IAEA）的全球监管组织，对最先进系统做系统检查、安全审计与算力/能耗监测；② 顶级实验室合并为一家机构（他称「Demis 方案」，参照 CERN 由多国共建共管）；③ 某家率先突破递归自我改进（RSI）形成垄断，最极端情况甚至有能力让竞争对手的 GPU 集体瘫痪（「Eliezer 方案」）——他直言这是「糟糕透顶」的结局，并明确反对把先进 AI 集中在单一企业手中。但他同时承认，OpenAI 目前无法轻易放弃与对手争夺领先地位。这条的价值不在新闻事实，而在头部实验室对「RSI 是分水岭」的自认与治理路径的分歧。⚠️ 二手报道的内部会议言论，OpenAI 未公开确认。
