**1️⃣ Hermes Agent 移动端进入内测：多 Agent 拉群、内置终端与 Skills/MCP，还能按权限读取手机数据**

Nous Research 的 Hermes Agent 移动端已进入内测，名额放出即被抢空；官方 11 月 3 日称需求超出预期，正在扩容并为更大范围发布做准备。据智东西汇总的开发者实测，App 支持两种模式：一是 SSH 等方式远程连接自己的主机，把手机变成 Agent 入口；二是走 Nous 官方云端托管，直接在手机上创建、调用、管理 Agent。功能上把桌面端能力大量搬了过来——多 Agent 可在同一群组内被分配任务（对应桌面 Bot Mode）、内置终端、Routines 定时任务页、Artifacts 产物预览、文件管理器，以及 Skills 的查看/启停/自建、Plugins 与 MCP Servers 独立管理入口。登录与计费：Nous 账号登录官方 Portal 需账户至少 2 美元余额，云端三档为标准（2 核 2GB、10 并发，0.60 美元/天）、专业（4 核 4GB、20 并发，1.08 美元/天）、旗舰（4 核 8GB、20 并发，2.50 美元/天），按月折算约 18–75 美元。最值得注意的新能力是 Device Access：经权限控制向 Agent 开放日历、联系人、位置、健康数据，但文章明确提示这些数据会上传至用户自己的服务器及所用 AI 服务商，敏感权限需谨慎开启。⚠️ 以上细节多来自社区开发者截图与自述，官方尚未逐项确认，正式版可能调整。

**2️⃣ 招商局狮子山实验室开源「驭物 Lion-ER-35B-A3B」：3B 激活、十项具身基准全线提升**

招商局先进技术研究院下属狮子山人工智能实验室发布具身推理视觉语言模型 Lion-ER-35B-A3B，MoE 架构总参 35B、每 token 仅激活约 3B，权重已在 Hugging Face 以 BF16 Safetensors 开源，兼容 Transformers/vLLM/SGLang。其路线不是堆数据，而是「能力牵引的数据引擎」：先把具身推理拆成实体、空间、时序、物理、可供性、任务、社会、证据 8 个一级领域、39 项二级能力，再把抽象能力「编译」成训练题，并从 31 个数据源、约 430 万条记录中按缺口检索素材；监督集共 31.2 万条样本，训练预算按能力需求而非数据源题量分配。效果用 avg@4 口径（每题独立作答 4 次取均值）：Where2Place 64.28（较基座 +9.30）、ERQA 64.38（+6.19）、空间推理 SAT 89.33、ERQA 轨迹理解子类 68.18（+12.12），十项基准得分均高于所用基座。⚠️ 注意对照口径：这是与自身基座 Qwen3.6-35B-A3B 的对比、且为团队自测，「多项超越更大参数量模型」未给出逐项对手名单，不宜读成行业 SOTA。文中四道公开题案例（相机转动方向、轨迹可达性、跨视角定位、任务进度判断）比分数更能说明它解决的是「视觉表象 vs 三维真实」的错配。

**3️⃣ 谷歌 Data Agent Kit 正式发布：37 个技能 + IAM 拒绝策略，把「能写 SQL」补成「懂数据上下文」**

谷歌结束整个夏季的预览，正式发布免费开源的 Data Agent Kit——一套 MCP 工具集，把编码智能体接到 15 项以上谷歌数据云服务（新增支持 BigQuery Graph、Bigtable、Spark 托管服务），可装在非谷歌智能体里，运行于 Antigravity、Claude Code、Codex、Cursor 及兼容 VS Code 的编辑器，并预装于 Cloud Shell 与 Cloud Workstations。架构是两层：承载最佳实践的「技能集合」+ 暴露实时元数据与工具的 MCP 服务器。插件仓库含 37 个技能（Apache 2.0、谷歌为发布方、有版本管理，9/29 发 1.0.0、10/13 发 1.1.0，可锁版本）。安全设计分两类且强度不同：一类是引导性的 accidental-data-loss-prevention，描述以「STOP AND VERIFY」开头，要求在执行 DROP TABLE、TRUNCATE、无 WHERE 或 1=1 的 DELETE、删生产存储桶、gcloud projects delete、销毁 KMS 密钥前暂停、说明影响、等用户确认——靠智能体自觉；另一类是强制性的 IAM，用只读服务账号身份模拟，或以拒绝策略拦截 tool.isReadOnly 为 false 的 MCP 工具调用，可在组织/文件夹/项目级生效。三个明确限制：被拦工具仍出现在 tools/list（智能体看得见、调了才知道不行）、只覆盖谷歌云 MCP 服务器、resource.service 与 tool.name 仅在 gcloud 可用。社区反馈更尖锐：工具返回结果不含幂等键、提交状态与可回滚性，超时后重试写入是否已提交仍无解。
