🤖 AI 资讯晚报 · 10-21

本期 144 篇新文章里，36氪 80 条大半是股市与个股东公告（已按画像剔除），真正落在 AI 主线的是三个方向：大模型开始接手完整科研流程、Agent 的能力上限被工程侧（而非参数）撬动、以及个人 Agent 撞上平台的商业围墙。以下按权重排序，概述均基于正文深读。

## 🔥 必读

**1️⃣ Claude 用 64 小时设计 31.8 万种蛋白，17 种通过实验验证**

Anthropic 公布一项生物学研究：与 Citrini Research 合作，让 Claude 从头设计能结合蝎毒神经毒素的 minibinder（微型结合蛋白）。流程上团队只给目标毒素、可用工具和筛选规则，Claude 自主检索蛋白结构、调用 **12 种蛋白设计工具**、生成 **318,484 个候选设计**、对 **55 万组**蛋白-毒素组合做结构预测，连续自主运行 24 小时后人工追加 4 次提示，计算阶段共耗 **64 小时、约 1 万 GPU 小时**，最后自选出 180 个候选（团队再补 31 个）。送 Adaptyv Bio 与 Twist Bioscience 实测的 211 个里，**17 个达到预设结合标准**：Cn2 7 个、AaH I 4 个、AaH II 4 个、LqhIII 2 个，Ts1 全军覆没；单靶点设计的成功率约 18%，Anthropic 称与常规蛋白设计研究相当。两个针对 Cn2 的候选（Cn2-B1/B2）KD 达个位数纳摩尔，竞争实验显示其结合位点与已知能中和该毒素的抗体 LR 相同或相近。

⚠️ 限定：只验证了「结合」，**没有做细胞层面中和测试、也没有动物体内保护实验**；原本想找的「一蛋白结合多种蝎毒」全部失败，17 个蛋白每个只结合单一毒素。211 个设计及数据已全部公开。另：今年 8 月 Anthropic 已公布过 15 个靶点中 14 个获实验验证的同类研究，本次是流程完整度的推进，不是从零突破。

**2️⃣ Agent 学会自己读论文改代码：微软与 UCSB 的 ScholarEvolve**

UCSB 与微软提出 ScholarEvolve，把「读文献 → 写实现 → 评测 → 合并」做成 Agent Harness 的自动演化闭环。做法是把 Harness 拆成工具接口、上下文、技能、记忆、工作流五个模块，先分析执行轨迹找出反复失败的能力缺口，再让 Research Agent 到 arXiv 检索——关键设计是**用 Topic Modeling 按技术机制给论文分类**，避免预算被几篇高度相似的工作吃光；随后 Coding Agent 把论文（含 GitHub 实现与附录里的 prompt 细节）落成代码、单模块测、再测组合。

不训练任何模型参数的结果：Qwen3.5-27B 在 AppWorld Normal 上 **69.0%→81.4%**；在含训练/验证阶段未出现过的 Amazon、Gmail 的 AppWorld Challenge 上 **49.6%→63.6%**（同设置下 Meta Harness 只到 54.6%）；GPT-5.4-mini 在 τ²-Bench Telecom 上 **72.7%→81.9%**。消融显示去掉文献指导、模块化搜索或 Topic Modeling，性能逐级下降——说明收益不只来自「自动改代码」。

⚠️ 这是 harness 层收益，不等于模型变强；且评测为两个标准 benchmark，真实业务的长尾尚未覆盖。对自建 Agent 系统的人（含本机 Hermes）参考价值直接：**能力瓶颈常常在脚手架而非权重**。

**3️⃣ 个人 Agent 撞上「平台门禁」：Muse 被亚马逊封，豆包手机助手遭 155 款 App 拒绝**

智东西梳理了个人 Agent 的第一道现实墙。海外：Meta 的 Muse（9 月 8 日上线，13 天登顶美区 App Store 免费榜）被亚马逊以「持续访问违反网站政策」为由抵制，xAI 的 Grok、OpenAI 的 Dots、Instinct 同样被拦；Yelp 只放行付费数据许可的 Agent，达美航空禁止 Agent 代订机票，摩根大通、嘉信理财以安全为由阻止 Agent 访问账户，阿迪达斯官网也拒绝 Muse 购物。国内：10 月 14 日豆包手机助手 SAEP 协议公示结束，**155 款主流 App 明确拒绝自动化操作**，含微信、QQ、腾讯会议等 66 款腾讯系与淘宝、支付宝、高德等 23 款阿里系，Kimi、DeepSeek 也关闭权限。

核心矛盾不是技术而是商业：Agent 一键直达结果、跳过首页与推荐流，平台丢的是曝光、数据与抽成，「安全」是表层理由。先例是亚马逊诉 Perplexity——一审禁止其 Agent 购物，8 月上诉法院推翻，边界至今未定。破局走的是折中路线：Meta 与沃尔玛、Gap、丝芙兰、百思买定向打通，Shopify 向 Agent 开放商城网络；阿里先在自己的淘宝、支付宝生态内闭环。Meta 与 Sierra 正牵头推「个人 Agent 协议」，OpenAI、Anthropic 尚未入局。

⚠️ 智东西的判断依据部分来自 The Verge/TechCrunch 转述，国内 155 款 App 的名单与拒绝方式以豆包公告为准，未见平台方公开回应。

**5️⃣ 极智嘉 Gravity Control：一句自然语言把 OOD 成功率从 5% 拉到 95%**

具身模型落地最大的坑是分布外偏移，传统纠偏要重采示教数据 + 微调重训。极智嘉的做法是**不训练、不加数据**，在推理时直接干预模型内部 latent feature：先用 Top-k SAE 在 Residual Stream 做稀疏特征分解，再用定向因果干预验证「哪些特征真的控制动作」。关键发现是「有概念 ≠ 具因果」——许多语言层表征能解码出语义却过不了因果测试，真正能驱动夹爪开合、位姿、速度的 MotorLayer 集中在动作专家（ActionExpert）深层。据此建概念控制表，操作员说「下夹取时抓得更深一点」即可在线 steering，Closed-loop Gate 限制干预剂量防动作发散。结果：OOD 复杂操作整体 **17.5%→87.5%**，单项设置 **5%→95%**，已在 π0.5、OpenVLA-OFT、LIBERO 与真机上评估。

⚠️ 厂商自述数据，未给样本量与统计置信区间；「语言层特征不可用」的结论基于其自建属性链验证。

**6️⃣ 生数科技把具身模型的训练过程直播半个月**
