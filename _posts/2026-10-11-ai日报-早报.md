**1️⃣ 长鑫存储 4F² DRAM 架构取得关键进展：自研 VSG 晶体管，年底推新一代服务器级 DDR5 RDIMM**

长鑫存储总裁**曹堪宇**在第四届集成芯片和芯粒大会（10-10）披露 4F² DRAM 架构研发进展，官宣预计**年底推出融合 4F² 与混合键合技术的新一代 DDR5 RDIMM**。4F² 相比业界主流 6F² 把单个存储单元面积再压三分之一（F 为最小特征尺寸），核心是长鑫自研的 **VSG（Vertical Surrounding Gate，垂直包围栅）晶体管**——用竖立沟道的垂直包围结构实现更强栅控，解决**漏电**（DRAM 靠电容电荷存 1/0，漏电会导致未刷新即数据错误，常规做法是提高刷新频率却换来更高功耗、更低性能功耗比）与短沟道效应，同时竖立布局助力面积微缩。长鑫自成立即布局 4F²，公开专利族**超 300 件**、数量领先海内外厂商，2021 年发**大陆首篇** 4F² 相关论文。另一关键是**晶圆级封装 / 混合键合**：把 DRAM 与 CMOS 工艺**解耦**再用晶圆级混合键合互联——区别于早期 4F² 把存储阵列与外围逻辑绑在同一套光刻 / 掺杂工艺里、导致位线 CBL 晶体管响应慢、寄生电阻高（也因此当年被业内搁浅）。长鑫自 **2019 年**起自研混合键合、公开专利已居**全球前十**；2025 年在 **IEDM** 首次在 12 英寸晶圆平台完成 **DRAM 与 CMOS 晶圆级键合**的实验验证。长鑫把 4F² 首代产品定为**服务器级 DDR5 RDIMM**（要 7×24 小时运行、抗热插拔电压冲击、过数百项与不同厂商 CPU / 主板的兼容测试）——直指服务器内存的技术与工程壁垒。⚠️ 演讲**未提及**该 DDR5 RDIMM 的**规格与发布时间**。

**2️⃣ 鸿蒙 PC 三大原生开发工具公测：DevEco 三件套把 Agentic 开发带进国产操作系统**

智东西 10-10 报道，10-8 华为三款**鸿蒙 PC 版**开发工具同步开启公测：**DevEco Studio**（一体化可视化 IDE）、**DevEco Code**（端到端 Agentic 开发工具）、**DevEco CLI**（AI 可调用的命令行能力套件），背景是鸿蒙 **HarmonyOS 6 / 7 硬件终端规模突破 9000 万**。**DevEco Studio** 基于华为自研「**毕方（BitFun）**」技术底座，主打快速启动、低资源占用，内置智能补全、错误提示、断点调试与内存分析，并集成 DevEco Code；用**自定义虚拟设备**无需装模拟器即可在鸿蒙 PC 上秒级启动调试手机 / 平板应用，窗口可切折叠屏等形态、支持多窗口并行（一次改动多端同步校验）。**DevEco Code** 内置模型服务并集成鸿蒙知识体系、Skills 与 MCP 工具，采用 **Goal / Plan / Build 分层可控**模式——**Plan+Build**：开发者先审方案、确认后授权执行，对未知改动零容忍；**Goal**：依需求 Spec 文档直出代码、自动完成验证与缺陷修复直至达标；可自主完成编译、运行与功能验证（治「AI 写代码一分钟、人工排错两小时」）。**DevEco CLI** 把 HarmonyOS 工具集、官方知识库与 **70 余项 Skills** 封装为适合 AI 调用的命令行接口、兼容主流 AI Agent（一行 `init` 把配套 Skills 批量装进本机多个 Agent 工具），覆盖多设备适配、知识检索、ArkTS 语法、应用质量等场景，并内置鸿蒙开发指南 / API 参考 / 最佳实践。意义：AI 辅助开发**正式落地鸿蒙 PC 原生体系**，鸿蒙 PC 从「应用运行终端」进化为「应用原生开发工作站」，补齐国产 OS 生态的关键短板。

**4️⃣ 亚马逊云科技在 Aurora DSQL 中引入外键约束，补齐 PostgreSQL 兼容的最大短板**

亚马逊云科技宣布 **Aurora DSQL**（无服务器、分布式、PostgreSQL 兼容）现已支持**外键约束**（含 **CASCADE / SET NULL** 等参照操作），弥补此前被用户列为**最大采用障碍**的缺口。实现靠「**事务期间快照验证 + 提交时冲突检测**」：**无需锁表**、基于一致性事务快照校验外键关系、提交时用隐式 **KEY SHARE** 检测冲突，违反约束的事务以**序列化错误**被拒（应用需实现重试逻辑，非等待）；对被频繁引用的键列，建议保持键稳定、把变化值移到非键列以减少冲突。AWS 副总裁兼杰出工程师 **Marc Brooker** 称其「**无阻塞**、不影响非外键读取的扩展性」。社区总体积极（荷兰国家铁路首席工程师称「他们做到了」），但也有用户质疑会**拖慢运行速度**——AWS 提示在添加外键前**先对工作负载做基准测试**（维护参照完整性会给被引用 / 引用表的所有 DML 带来额外读取）。同期 DSQL 还新增 CloudWatch Database Insights。
