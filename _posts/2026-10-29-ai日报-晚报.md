**1️⃣ 腾讯 Buddy One：五款办公产品共享一个 Agent 底座，账号、积分与跨产品检索全部打通**

10 月 29 日腾讯全球数字生态大会上，腾讯发布面向个人的跨应用 AI 协同体系 Buddy One：以 WorkBuddy 为工作台，连接腾讯文档、腾讯会议、腾讯网盘、ima，共享同一套 WorkBuddy Agent 底座（各产品调用的是 WorkBuddy 的 Harness），并用 Buddy One ID 打通账号、积分与跨产品上下文检索。实际用法是「帮我汇总本周某项目的资料」——WorkBuddy 会同时检索资料库、腾讯文档、ima、腾讯网盘，汇总后生成方案并附来源，省掉过去逐一开应用复制材料的过程。积分池统一后可在四个产品通用（腾讯会议暂不消耗积分），关联机制目前免费，PC 端 5.9.0 以上即可绑定。

同场还发布了腾讯网盘，定位是「面向 Agent 时代的记忆空间」，为套件提供统一存储，让任务留下的过程文档与成果成为下次可复用的资产；外部信息由元宝搜索补足（千亿级索引、13 个垂直领域 157 家信源）。企业侧则开放架构：可接自研/第三方 Agent 与第三方 IM，用 MCP、连接器连 ERP/CRM/OA，模型可选混元、DeepSeek、GLM、MiniMax、Kimi 或自部署；案例是一家头部制造企业通过 MCP 直连经销商系统，每月自动初审 2 万单索赔发票。混元 Hy4 与 Hy4 flash 宣布近期推出。

⚠️ 限定：腾讯所说的「进一步记忆共享」仍是后续规划，当前只做到授权范围内的上下文打通与跨产品检索——这两件事不能混为一谈。

**2️⃣ 拓元智慧开源 E0.5：用「未来几何」直接监督动作，真机最高超 π0.5 26.7 个百分点**

X-Era AI 拓元智慧开源原生 4D 世界动作模型 E0.5（arXiv 2610.36011、代码在 GitHub X-EraAI/e05）。核心思路是把空间建模与物理建模解耦：空间侧负责几何、物理侧负责动力学演化，用「预测未来若干步的三维几何」作为动作学习的原生监督信号，再把预测翻译成连续可纠错的动作——它关心的不是「看见物体」，而是「物体将如何变化」。

真机数据相当硬：在 AgileX Piper 双臂与 Zerith H1 人形上，经约 16 万条真实轨迹（AgiBotWorld-Beta）预训练后，跨分布内/外整体平均成功率 85.0% 与 88.3%，比 π0.5 高 13.3 与 26.7 个百分点；分布内 96.7% 与 100%。更能说明问题的是「不做具身预训练、直接任务后训练」的对照：Piper 86.7% vs π0.5 的 46.7%、H1 93.3% vs 70.0%，差 40 与 23.3 个百分点；OOD 垃圾清理 H1 从 20% 提到 80%。刚柔混合的「充电器+线缆收纳」任务提升 20–40 个百分点，恰恰是最依赖几何后果判断的一类。全部真机试验 480 次。

⚠️ 数据均为团队自测、基线是 π0.5，未见第三方复现；预训练轨迹规模与真机集群条件也非普通团队可复制。

**3️⃣ 蚂蚁开源 AntOmniEvo：把「调 AI 系统」这件事本身交给 AI，失败候选不丢弃**

蚂蚁灵矽开源 AntOmniEvo——一个自动优化 AI 系统的框架。你只提供四样东西：待优化系统里「可修改部分」的文件目录（prompt、规则、脚本、配置）、评估数据、打分标准、系统怎么跑；剩下由框架驱动 coding agent 在「改文件 → 跑评估 → 看分数」的循环里 7×24 迭代。产物是一目录可直接部署的文件，每处改动可 diff、可 review、可回滚，过程全白盒落盘。

算法上两个设计值得记：① Mara Chain——没及格的候选**带着诊断记录留下来**继续修，下一代继承逐题分数、历代诊断、逐代改动与原始轨迹，专治「同一个错误反复诊断」的顽固失败壁垒；② pareto 过滤的 top-N 选择——先按逐题 Pareto 保留「总分平平但某道难题全场最强」的候选，再按总分截断，避免偏科生被系统性杀掉。消融给得很实：关掉任一机制，爬到同一分数分别要多花约 1.5 倍与 2.3 倍 rollout，且终态都够不到 0.87；TerminalBench 上关掉 Mara Chain，通过率从 71.9% 掉到 57.3%。

⚠️ 基准与打分器由团队自建，数字为自测口径；「optimize anything」目前覆盖 skill、agent harness、检索管线三类形态。

**8️⃣ RobotAgentBench：独立 VLA 的任务发现得分不到 2 分，瓶颈在 harness 不在策略**

Aether AI 与 UC San Diego 提出开放世界机器人评测 RobotAgentBench：50 种家庭布局、90 项原子任务、18 项短程、8 项长程与 4 类开放场景，按操作、任务发现、情境推理、失败恢复、鲁棒性五维打分，比较 8 个 VLA、3 个 WAM 与 Codex/Claude Code/Antigravity CLI 等编码智能体。结果很尖锐：独立 VLA/WAM 的任务发现得分全部低于 2，开放场景综合最高仅 2.0，InternVLA-A1.5 与 OpenWAM-Alpha 在开放场景停滞时间占比 88.3% 与 84.6%——会操作，但不会「自己找活干」。加入 Agent 框架后跃升：Codex + InternVLA-A1.5 混合配置任务级均分 48.5、开放场景 15.4 为最高；纯代码配置中 Antigravity 39.7、情境推理 80.0；RSI 还能让智能体持续改进控制工具。
