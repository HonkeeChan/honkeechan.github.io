### 1. 英伟达官方确认黄仁勋辞职：CFO 克雷斯任临时 CEO，股价一度跌近 14%

### 2. 谷歌发布 Gemini 4 Hydrogen：Flash 级模型跑分反超自家 Argon，并成为搜索 AI Mode 默认模型

- 来源：[机器之心](https://www.jiqizhixin.com/articles/2026-11-13-3)｜[爱范儿](https://www.ifanr.com/1689267)｜[官方博客](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-hydrogen/)

11-12，谷歌发布 **Gemini 4 Hydrogen**，同步推出多模型调度系统 **Orchestrator**。定位是 Gemini 4 矩阵里的「快速执行引擎」——Carbon 与 Argon 负责深度推理与复杂任务，Hydrogen 接替 Gemini 3.8 Flash，主打低延迟、低成本与 Agent 执行，适合日常编码、智能体工作流与多步骤数据处理。原生多模态，输入/思考/输出**共享 100 万 token 窗口**，最大输出亦为 100 万 token。

硬数据：Artificial Analysis 智能指数默认 High 档 **51 分**、新增 xhigh 档 **54 分**，**反超自家更大参数的 Argon（50 分）**，仅比 Claude Sonnet 5.5 与 GPT-6.1 Sol 的最高档低 1 分。速度方面，相比 3.8 Flash 任务完成快 **2.5 倍**；Terminal-Bench 4.1 从 **18.2% 升至 57%**（三倍多），幻觉减少 5 倍以上（AA-Omniscience 幻觉率 **8%**，Sonnet 5.5 为 43%、GPT-6.1 Sol 为 52%）；输出约 **200 tokens/s**。短板也很明确：Terminal-Bench 4.0 得 **54%**，低于 Sonnet 5.5 的 64% 与 GPT-6.1 Sol 的 56%。定价每百万输入 **1.5 美元**、缓存命中 0.075 美元、输出 **7.5 美元**，全上下文窗口统一价；xhigh 档单任务成本约 3.16 美元、High 档 1.87 美元，仅为 Sonnet 5.5 最高档的 **32%**，但仍是 GPT-6.1 Sol 的约 2.5 倍。

Orchestrator 可在同一会话内动态切换 Carbon 与 Hydrogen：Terminal-Bench 4.0 中任务成功率接近纯 Carbon，配额消耗 **-24%**、速度 **+19%**，已先向 Ultra 用户开放。分发是这次更关键的一步——Hydrogen 已成为**谷歌搜索 AI Mode 的默认模型**、承接 AI Overviews 复杂查询的底层推理，并进入 Gemini 应用（免费用户经 Auto 路由）、AI Studio、Gemini API 免费层、Gemini for Business 与 Antigravity。实测侧，开发者用它一句话生成可漫游 3D 港湾/城市、2D 动画与电商站点；官方演示里它读一段 YouTube 演讲视频 + 设计模板，直接在 Google Slides 生成多页演示并自查排版。

> 判据：这是「小模型 + 调度器」对「大模型单打独斗」的一次定价与体验双杀——前沿能力不再只靠最大参数，而是靠路由把便宜模型放到 80% 的日常步骤上。

### 3. MiniMax 开源 H3 Image：原生 4K、10 秒出图，Artificial Analysis 开放权重双榜第一

- 来源：[机器之心](https://www.jiqizhixin.com/articles/2026-11-12-12)｜[量子位](https://www.qbitai.com/2026/11/509440.html)｜[GitHub](https://github.com/MiniMax-AI/MiniMax-H3-Image)｜[HuggingFace](https://huggingface.co/MiniMaxAI/MiniMax-H3-Image)

MiniMax 发布图像模型 **MiniMax H3 Image** 并**当天开放权重**（本周二开源），核心参数：**原生 4K 直出**（最高 4096×4096）、**10 秒级生成**、支持最多 **16 张参考图**，可通过 API 接入 MiniMax Code 或其他 Agent Harness 完成任务。在更新后的 Artificial Analysis 榜单上，H3-Image 在**文生图与图像编辑两项均位列开放权重模型第一**，社区因此出现「GPT is cooked」的说法。

机器之心的实测按四个维度展开，结论有具体指向：**真实感**——生成的微信聊天截图在状态栏、气泡间距、头像与产品照片高光上都经得起看，人像不再有「塑料皮」，毛孔、雀斑、汗毛清晰；**文字渲染**——让模型在地铁涂鸦上拼出「MiniMax H3 Image」长串字母，立体造型、渐变填充、喷漆垂流都成立；**人像一致性**——维密后台、电影感街头回眸、千禧年直闪三组参考图生图，面部保持与复杂服饰细节都在线；**二次创作**——图生图的风格迁移可用。模型已在 MiniMax Code 上线，支持网页端与 API，开源后已有本地部署实践。

> 判据：开源图像模型的竞争点已从「像不像」转到「能不能直接进生产工作流」——4K 直出省掉超分环节，16 张参考图让角色/商品一致性可控，开放的权重则让私有化部署成为选项。对内容生产管线而言，这是一次成本结构变化，不只是榜单名次变化。

### 5. 斯坦福只改 65 行词嵌入，修好机器人「换种说法就失败」：留出集 74.3%→87.5%

- 来源：[机器之心](https://www.jiqizhixin.com/articles/2026-11-13-5)｜[论文](https://arxiv.org/abs/2611.09376)｜[代码](https://github.com/jushengzhang/robot-weight-debugging)

论文《Can LLMs Debug Robots by Editing Their Weights?》把 GPT-6 Astra 放进「调试器」位置：给一个持续保留状态的 Python 工作区与前向工具，让它查看张量、写入替换值、再看仿真结果，每次编辑预算 50 次工具请求，**不做梯度更新、不加机器人示范数据**。最终修改集中在词嵌入表：**65 行、132,768 个参数值，仅占检查点 0.00367%**，做法是把向量移向更常见的任务表达（cooker→stove、basin→bowl、fermented→wine）。效果：765 条留出改写指令上总成功率 **86.3%→92.0%**（48 个回合修复、4 个退化，净增 44，p=1.31×10⁻¹⁰）；其中**包含被改词元的 335 条**从 **74.3%→87.5%**，**不含被改词元的 430 条成败逐一不变**，最难一级改写 59.8%→78.2%。示例：指令「activate the cooking appliances heat source」原本去拿盘子、300 步超时，编辑后第 78 步完成。
