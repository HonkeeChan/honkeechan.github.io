### 1. Manifold AI 推出 R²SI：双层 Agent 让机器人从自己的失败里改 Skill，RoboDojo Agent Track 登顶

Manifold AI（流形空间）的 WorldScape R²SI 在 RoboDojo 机器人学习基准的 Agent Track 位列第一，超过 GPT-6-Astra 与英伟达 GR00T-N1.7。方法核心是一套内外双层 Agent 的递归自进化闭环：内层 Robot Agent 以多视角 RGB、机器人本体状态、任务描述与回合记忆为上下文决策，按任务加载 Skill 执行；外层 Recursion Agent 跨轮次复盘执行记录、直接修订 Skill，并以 Harness 更新的形式作用回内层。对调用 reactive model（WSP）的任务，外层还把执行记录组织成训练数据来更新该模型。关键约束是「所有更新必须通过测试才能自动发布并纳入版本管理」——这是把 Agent 的自我修改关进了回归测试里。

推送任务 push_T 的案例最能说明机制：首轮因夹持方向不匹配、平移与转向同步导致物体偏转，一次性释放又偏离位姿，共耗 723 步、超出 600 步预算；外层据此把「调整夹持方向、平移与分段转向解耦、分阶段释放并逐段检查偏移」写进 Skill，首次即在预算内拿到原生满分（596 步），再迭代降至 389 步（-35%）；Skill 冻结后，内层在三种随机布局上分别以 222 / 312 / 256 步自主完成且均满分。

⚠️ 两点保留：这是厂商自述的榜单成绩，文章未给完整评分表；且 10-15 晚报必读的 EinsiaAI EmbodiedEvo 同样宣称登顶 RoboDojo（45.08 平均分），本期这条限定在 Agent Track，两者子榜口径需以榜单官网为准，不能直接比大小。

### 2. 港大 EgoWild2Dex：538.9 小时「极脏」第一视角人类数据，每个任务不到 1 小时真机数据，成功率 96.7%

香港大学 MMLab 的思路很直接：不再把训练数据「拍干净」，而是直接采集人类在家庭、工厂、药房、医院、超市、包裹站里本来就在做的操作——相机随人走动剧烈晃动（每秒头部累计旋转 15.93°、每帧平均 34.78 个物体实例）、背景杂乱、物体长尾。用 538.9 小时这样的数据（17.9 万个操作片段、12.6 万条任务描述、1282 个物体类别）预训练，再配合每个下游任务不到 1 小时的真机数据，机器人能连续完成「美工刀划开胶带开箱」「热熔胶枪固定摆件」「铲冰做冷饮」三个长时序双臂任务，平均成功率 96.7%。

两个对齐是关键。视觉侧用 GeoFormer（轻量、可微的几何变换）把人类头部视角动态对齐到机器人视角，比传统「精确标定 + 三维重投影 + 图像修复」流程快 21.9 倍，且不要求采集者为了迁就机器人而稳住相机；动作侧用重定向 + 逆运动学，把人类第一视角数据、机器人视角的手套演示、真机演示映射进统一的原生动作空间，然后三段训练：大规模人类数据预训练 → 人机协同 → 真机精调。

⚠️ 标题里的 96.7% 是三个已训任务的均值，面对训练中未见过的箱内物体，零样本成功率只有 33.3%；论文已上 arXiv，数据集与代码目前是「计划开放」而非已开放。其真正价值不在某个成功率，而在把「人类日常操作」变成可规模化的机器人数据来源。

### 3. Anthropic「北极星项目」：600 亿美元债务融资买 1.5 吉瓦谷歌 TPU，黑石认购 90 亿

据报 Anthropic 正为代号「北极星项目」（Project North Star）的 600 亿美元债务融资筹资，用途是采购约 1.5 吉瓦由谷歌开发的定制 TPU。为吸引资金，Anthropic 向黑石提供超过 10% 的收益率；黑石旗下基金拟投 90 亿美元，购买以 Anthropic 未来五年芯片租赁付款为支撑的债务，约占总额 180 亿美元次级贷款的一半。若落地，这将是迄今规模最大的芯片融资交易，也被视为检验投资者对 AI 相关债务需求的关键测试。

值得注意的是融资结构的变化：不再是股权融资买卡，而是把算力采购转成以未来租赁现金流为抵押的债务——等于用预期的 API 收入给当下的算力扩张加杠杆。这与前几日「Anthropic 三季度营收 168 亿美元、首次盈利、冲刺 IPO」是同一盘棋的两面：一边证明收入曲线，一边把资本开支移出资产负债表。风险也随之转移给债务持有人。

⚠️ 消息源自匿名知情人士，Anthropic 与黑石均未公开确认金额与收益率细节，10% 以上收益率本身也说明这类债务的定价并不便宜。

### 5. 摩根士丹利：2027 年超大规模与新兴云厂商数据中心新增算力同比激增 48%，达 32 吉瓦

预测 2027 年超大规模云厂商与新兴云的数据中心新增算力规模同比增长 48%、达到 32 吉瓦，其中谷歌、亚马逊、微软、Meta 四家贡献约 85% 的新增建设量；2028 年再新增 39 吉瓦，同比扩张 21%。

含义是算力供给仍在加速而非收敛：新增算力的增速（48%）高于单卡效率提升的常规节奏，意味着电力与并网正在取代芯片成为更硬的约束——可对照 10-17 早报里微软与 NiSource 签 20 年供电协议、为印第安纳园区新增约 1100 兆瓦那条。⚠️ 卖方预测而非实测数据，且 85% 的集中度本身也是风险提示：四家资本开支的边际变化会直接决定整条供应链的景气。

### 7. 「风清」AI 气象预报系统业务化运行：全球有效预报时效 11 天，综合效果超 ECMWF

「风清」人工智能全球短中期集合天气预报系统 V1.0 通过业务化评审并投入运行。它全程依托国家超算互联网核心节点的十万卡 AI4S 计算集群完成训练，是「全国首个实现数据、模型、算力全自主」的业务应用气象 AI 集合预报模型，全球有效预报时效达 11 天，综合预报效果超过欧洲中期天气预报中心（ECMWF）的人工智能集合预报系统。
