### 1. MIT 韩松团队开源 PEAR：27B 千问模型纯仿真 RL 后直接上真机，30 次成功 18 次

MIT 韩松团队公布机器人后训练项目 **PEAR**（Post-training Engine for Agentic Robotics）：以开源 **Qwen3.8-27B** 为底座，**不需要一帧人类遥操演示、不需要一条真机数据**，只在仿真环境里做强化学习，训完直接部署到一台它从未见过的双臂 YAM 真机，30 次测试成功 **18 次**（训练前 0 次）。

方法叫 **Robot-Use RL**，逻辑与「Computer Use」同构：每回合输入三路摄像头画面 + 机械臂当前关节状态，模型在思维链里推理（「夹爪在橡皮正上方，把手指降到橡皮两侧」），输出一段含末端执行器下一目标位姿（x/y/z/roll/pitch/yaw）的 JSON，逆运动学算关节角、底层控制器驱动到位，本轮记录连同新画面回填上下文进入下一回合——**全程没有感知模块、没有抓取规划器、没有技能库**。

基准成绩：LIBERO 零样本 1.6% → **74.4%**（GPT-6 Astra medium 49.3% / max 76.2%，GPT-6.1 Sol medium 48.1% / max 80.6%；PEAR 用 xhigh 档）。关键在扰动测试：π0.5 原版 96.9% 高于 PEAR，但**任务替换**（同场景只换指令）时 π0.5 跌到 **0.75%**（-96.2 分）、PEAR 74.4%→57.4%（-17）；**布局替换**时 π0.5 跌到 20.8%、PEAR 57.5%——π0.5 记住的是运动模式，模式失效就全崩，PEAR 保留的是指令理解与视觉感知，靠画面重新生成位姿。

跨环境迁移：训练后零样本在 LIBERO-Long 拿 39.0%（底座 0.4%）；换双臂 ARX 的 RoboDojo 仿真器 general_pickup 39.9%（底座 10.7%）；RoboLab-120 37.3%（底座 5.4%，对照 Cosmos3-Nano-Policy 36.8%、π0.5 28.0%、DreamZero 25.7%、GR00T N1.6 7.2%）。工程指标：**RTX 5090 上 220+ tok/s**，可本地运行；且相比底座在 AIME、GPQA、LiveCodeBench 等九项通用 benchmark 上分数几乎不变——**没有牺牲数学与编程能力**。

已核实：[GitHub 仓库](https://github.com/mit-han-lab/pear)真实存在（Apache-2.0，2026-11-13 建库，237 stars）。

判读：这是「通用大模型直接接管机器人」与「专用 VLA 死记轨迹」之外**第三条路**——用后训练把通用模型的动作输出接口对齐到机械臂，代价只有仿真算力。真实约束也清楚：真机 18/30 = 60%，离可商用还有距离；论文为预印本，尚无第三方复现。

### 2. Claude 读完哥德尔 1009 页速记手稿：663 条定理雏形，400 条形式化验证通过

芬兰赫尔辛基大学逻辑学家 **Jan von Plato** 2017 年强制退休后，申请到欧洲研究理事会 **250 万欧元**资助，专攻哥德尔 1940 年定居普林斯顿后写下的 **16 本工作簿、共 1009 页**笔记。难点是双重的：笔记用已近乎失传的**加贝尔斯贝格速记**（Gabelsberger）写成，全球能读的人据其自述「大概六个」；团队花数年逐页转写成现代英文后，仍卡在理解——笔记高度浓缩、满是直觉草图和未展开公式，进度约**每周一页、一年 50 页**。

转机出现在今年夏天法国一场「AI 与定理证明」会议：几位计算机科学家建议他试 Claude。他把 1009 页转写稿＋自己 6 本专著＋大量现代逻辑文献一并输入，几天后得到 **650 页**解读，持续追问后膨胀到 **1084 页**。更实质的产出是：Claude 梳理出 **663 条具备定理雏形**的结果，在计算机科学家 Josef Urban 等人协助与形式化验证下，**400 条被证明完全成立**，约 200 条核心思路无误但需补充前置假设，**55 条是错的**，还有几条仍在验证。换算下来，哥德尔在 1940 年代初逃难到美国不到三年里，几乎每两天产出一条新定理。

von Plato 在维也纳大学演讲里把 Claude 比作「数字怪物」、有「莫扎特式视野」——它能把第 12 页的灵感与第 890 页的公式同时「在场」地联系起来。

⚠️ 口径纪律：标题所称「他离菲奖只剩最后一步」指文中一段**二手回忆**——1963 年 Paul Cohen 用力迫法证明选择公理独立性并于 1966 年获菲尔兹奖；Alonzo Church 在颁奖礼上公开称哥德尔 1942 年已在类型论框架下证出可构成性公理独立性；Cohen 2002 年撰文回忆当面求证时，哥德尔承认「确有方法」但否认与类型论有关、且不肯透露。此事**无原始手稿或论文佐证，属未经独立核实的回忆**，本期不采信为事实。可核验的核心只有数字部分（1009 页 / 663 → 400 / 55）。

判读：与 11-14「Claude Code 形式化三元哥德巴赫」是**不同事件但同一机制**——AI 的价值不是「想出新数学」，而是**把人类写不动、读不完的长文本变成可逐条验证的清单**，且验证环节仍要靠形式化内核。注意 55 条判错这个数字同样重要：它是「AI 输出必须过验证器」最直接的证据。

### 3. 「史上最严」湿实验预测基准 SPU：116 任务 4207 个实验，最强模型仅 0.486 分

UniPat AI 牵头发布 **Science Prediction Universe（SPU）**：不给模型刷题，而是给一组实验条件，让它**提前预测真实湿实验结果**（同一反应换几种条件哪种产率更高、一批抗体变体哪个表达量更高），答案藏起来，等模型交卷再拿实测结果对照。

规模：**116 个任务、4207 个湿实验、32 个子领域**，覆盖化学、材料科学、生物与医学；其中 100 个公开任务取自 **85 篇近期论文**（由领域专家整理候选项、材料、条件与测量方式，保留完整定量结果作评分依据），16 个私有任务来自**四组未发表的合作湿实验**（VHH 纳米抗体、反应条件、电解液、Magrolimab 变体）——后者用于排除「模型见过答案」。基准顾问与湿实验合作方来自斯坦福、康奈尔、哈佛等十余家机构。为避免趋势过强或数值过近的题，专家剔除了可沿单一趋势排序的简单题。

评测条件刻意接近真实科研：每次运行 **8 小时**、8 核 CPU / 16 GiB 内存 / 一块 **H20**，允许联网检索并自行安装科研软件，模型自主决定怎么用检索与计算资源，最后提交各比较组从低到高的**预测排序**；评分用 Spearman 相关系数，全程在断网容器中进行并扫描工具输出里的 DOI、标题等标识符防泄漏；每题额外生成 **4000 份随机排序**、取第 95 百分位作随机水平阈值，防止「瞎猫碰死耗子」。

结果：覆盖 **12 款前沿模型、13 种配置**（模型＋推理强度＋框架），平均分最高为 **Claude Opus 5.5 的 0.486**，且它也只有一半任务超过随机水平；13 个配置能超过随机阈值的任务比例仅 **34%–52%**。领先组（6 个）比落后组（7 个）同题高约 **0.15** 分；领先组约 9% 的任务得分为负（负相关），落后组高达 22%。

个案很能说明问题：同一个聚合反应依次更换 12 种溶剂、要求按分离得到的聚合物质量排序（66 个两两配对），Opus 5.5 得 **0.874**、排对 56 对；Qwen3.8 得 **-0.126**、只排对 30 对——差别从第一步就出现，Qwen 主要按溶剂对乙烯的溶解度排序，Opus 则关注原料混溶性与催化剂在溶剂中的行为。

判读：结论是负面的，但信息量极高——**「推理拉满、算力翻 5 倍」在湿实验预测上收益有限**，短板在科学品味（该关注哪个机制），不在算力。对做 AI for Science 的团队，SPU 是目前唯一能把「科研直觉」变成可复现分数的公开标尺。

### 4. 中科院自动化所 + 美团 RSI 综述：Prompt / Memory / Skill / Harness 四组件，When–Where–How 三问

中科院自动化所、美团联合山东大学、中国人民大学、中科院微电子所、上海交通大学、理想汽车等推出 LLM Agent 递归自我改进（RSI）综述。起点是一个具体场景：编程 Agent 调 API 报错、几轮试错后修好——但下个任务还会不会犯同样的错？这次修复能否沉淀成规则、记忆或技能？

综述的主线是**模型权重不变，Agent 行为也能变好**：把反复验证有效的约束写进 Prompt、把用户更新存入 Memory、把成功流程整理成 Skill、按重复失败调整 Harness 的工具接口与检查逻辑。所谓「递归」还有一层要求：保留下来的经验要能**参与后续修改的诊断、生成或筛选**——上次的修复记录帮你定位下次的失败，已有的更新经验帮你选更有效的修改策略。

框架用三问组织：**When**（何时更新、何时保留：失败/新信息/接口变化都可能触发，但能否留下要看后续任务表现）、**Where**（改哪个组件：指令没说清、信息过期、步骤缺失、还是运行机制容许跳过检查——须由执行证据支持）、**How**（如何从日志提炼适用范围明确的规则，再验证「修了目标问题且没伤原能力」才纳入）。方法上覆盖四条演进线：Prompt 优化从「搜一条更好的指令」→「用失败反馈修订」→「优化负责生成指令的那个 Agent 的提示词」；Memory 从解决容量→提炼可复用经验规则→管理时效与适用对象（用户搬家后配送要用新地址、查历史仍要旧地址）→按后续反馈动态调整记忆效用；Skill 与 Harness 两条线同样从「生成候选」走向「修订、选择与长期维护」。论文以 40 项代表性研究绘制全景、对 20 项研究的更新闭环做对照。

判读：这是四天来 RSI 系列（11-12 Trinity、11-13 百度伐谋、11-14 HiPhys-RSI 与 MolRSI）里**唯一给框架而非单点结果**的一篇，且四组件与 Hermes 的 skill / memory / harness 三层几乎一一对应——最缺的仍是「修改后如何验证没伤原能力」这一步。

### 5. EMNLP 2026 杰出论文 OptiMer：合并分布向量代替数据配比，试 100 次配比只需 8.5 小时

日本信息通信研究机构（NICT）宋海越团队的工作获 **EMNLP 2026 杰出论文奖**（17,661 篇投稿中仅 22 篇）。要解决的问题是持续预训练中的数据配比：各数据集放多少只能训前定、训完才知道好坏，配比不对往往从头训，试错成本极高。

OptiMer 三步走：① 从基座模型出发，在日语、中文、数学等各数据集上**分别**做持续预训练；② 用训练后参数减去基座参数，得到每个数据集的**分布向量**；③ 基座权重 + 不同比例的多个分布向量 + 指令遵循向量，用**贝叶斯优化**搜最优合并比例——每次尝试只含「合并 + 评估」，**不再训练**。

效率：传统数据混合试一个配比需 **129.3 小时**，OptiMer 试 **100 次**配比仅 **8.5 小时**，配比最优化阶段加速 **15–35 倍**。效果：C-Eval、Japanese Leaderboard、MMLU、GSM8K、HumanEval 平均 **70.37**，高于传统数据混合的 **63.71**（约 +6.7 分）；且搜到的合并权重可直接当数据配比用，重新训练后平均分从等比例混合的 63.71 升到 **68.66**。

为什么能合并：实测分布向量两两余弦相似度约 **0.3**，而分布向量与指令遵循向量之间仅约 **0.03**（接近垂直），所以 DARE 这类合并算法可较无损地叠加。机制分析显示模型不能偏离基座太远——分布向量模长随训练增长，模型表现在训练早期达峰后逐渐下降；PCA 轨迹近似一条直线，增减权重等价于增减该数据上的有效训练量；权重可设负值做「机器反学习」，论文未深入。

落地案例：对 Gemma-SEA-LION-v4-27B（基于 Gemma 3、已在东南亚语料上持续预训练）分别抽取日语/中文/英语/数学/代码五个分布向量再合并，日语得分 **66.34 → 74.40**，同时保住东南亚语言能力。

判读：对工业界的直接价值是**特化模型可以「拼」出来而不是「训」出来**——想换领域只换评估目标、重搜权重，不必重跑预训练。局限：只在持续预训练上验证，后训练阶段未测。

### 6. 星舰第 15 次试飞：上面级飞船首次被发射塔机械臂捕获，助推器坠海未实现双回收

在轨飞行 **22 小时**、绕地球 **14 圈**后，高约 **52 米**的星舰上面级飞船重返大气层飞回得州星舰基地，在离地不远处重新点燃发动机、完成翻转与减速，精准进入发射塔两条机械臂之间，随后发动机关闭、被稳稳夹住——这是**人类首次成功捕获从地球轨道返回的星舰上面级**。此次还顺带部署了 **26 颗星链 V3** 卫星，其中部分搭载专用相机，从外部反向检查飞船隔热盾状态。

技术难点在再入：入轨速度约 **7.8 km/s**，靠迎风侧数千块隔热瓦保护不锈钢箭体；本次改进了瓦片固定方式并采用新的**弧形隔热瓦**设计以降低缝隙局部加热；返回姿态走「腹部下落」（Belly Flop），近地再点火翻转成垂直姿态入塔。马斯克发射前称将尝试**同时捕获助推器与上面级**，若两边都成，就是一套轨道火箭的全部主要飞行部分首次完整返回——但**超重型助推器返回过程中出现异常，最终坠入墨西哥湾**，双回收未达成。

判读：猎鹰 9 号十多年来只能回收一级，二级一次性抛弃；星舰这次补上的是「第二级也回得来」这块最后拼图。但注意口径：**这是单次成功 + 单级成功**，两级全回收、快速复用周转都还没验证；把上面级直接送回发射塔的价值在于省掉海上打捞、运输与重新吊装。

### 7. 李沐出任 Aimotion 联合创始人兼 CTO：做「产业级世界模型」，建模商业规则而非物理

李沐正式出任 **Aimotion** 联合创始人兼 CTO，主导下一代产业级 AI 技术体系建设；**同时继续担任 Boson AI 联合创始人兼 CTO**——不是跳槽，而是两家联手，联合攻关产业级世界模型与商业 AI Agent。

判读：「世界模型」出现了**物理 → 商业**的分叉，这条线的判据不再是仿真保真度，而是业务因果是否正确。⚠️ 目前只有人事与方向公告，无技术报告、无产品，融资为数千万美元 A 轮量级，不宜过度外推。
