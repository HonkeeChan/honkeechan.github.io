**1️⃣ MIT「权重空间编程」：GPT-6 Astra 只改 0.016% 参数，Qwen 数学成绩 7.9% → 48.1%**

MIT CSAIL 让通用大模型直接读取、直接改写神经网络的原始权重，全程不用梯度下降、不重训。最硬的一组：把 Qwen3.5-0.8B 的权重交给 GPT-6 Astra，它定位到让模型反复陷入推理循环的参数，只改动约 0.016%，MATH-500 从 7.9% 升到 48.1%，指令遵循能力同时提升近两倍。其余七组实验覆盖：仅凭权重判断网络打过哪款游戏（未给候选范围也全对）、判断三个 DDPM 各生成圆/三角/方（它画出空心轮廓，反证是读结构而非跑前向）、去掉首尾层只看四个 Transformer 块判断训练语种；以及「从零写权重」——为 MinAtar 三款游戏和围棋手写网络，其中围棋策略网络超过经 1 亿步 PPO 训练的模型。团队把这一能力命名为 Weight-Space Programming，并明说它指向 RSI 的一条新进路。

⚠️ 作者自述是「非常早期的实验结果」，主体为小网络（0.8B 与 720 万参数级）；MATH-500 的 7.9% 基线本身极低，「6 倍」是相对这个低基数；无第三方复现。

**2️⃣ CyberArena：466 场双向攻防，把「漏洞解决率 80%+」打回原形**

现有 CTF/Cybench/CyberGym 高分基本来自单机答题——靶机不打补丁、不重启、不反打。2077AI、UC Berkeley RDI、UC Santa Cruz、UCSB 等设计的 CyberArena 改成对称攻防：12 款前沿模型 + harness 组合，每场 3 轮、每轮 20 分钟，攻方要夺旗、守方补的丁会保留，且为防守直接关服务会因可用性检查丢分。跑完 22 批次、466 场有效对局后分层明显：GPT-5.6 Sol（跑在 OpenAI Codex）78.6 第一，Claude Opus 5（Claude Code）73.8 第二，智谱开源 GLM-5.3（OpenCode）68.5 第三，其余 56.3–67.1；前两名对局胜率 0.83 / 0.86，其余最高仅 0.59。最关键的对照：40 题里 30 题是 Sol、Claude Opus 4.8、GLM-5.3 都能单人全解，搬进对抗赛后到第 3 轮，三者进攻捕获率分别跌到 52%、37%、35%。40 道赛题中 14 道来自 saarCTF / FAUST / DEF CON CTF 决赛，26 道取自真实公开漏洞（优先 CISA KEV 或有公开利用的 CVE）；12 款模型共调用 53,511 次 MCP 工具。排名用潜变量能力建模 + Laplace 近似逐批重拟合，Bradley–Terry 交叉验证 Kendall τ=0.85。

⚠️ 该得分是潜变量估计的**相对分**、不是绝对比分；前两名在直接交手中 3 胜 2 负 3 平，对调在统计上不显著（p=0.41）。

**3️⃣ HarnessSQL：8B 反超 32B，首个原生长程交互训练的 SQL Agent 框架**

传统 Text-to-SQL 把问题压成「给定 Schema 一步出 SQL」，而真实库动辄上百张表、数千字段，分析师其实是 `SHOW TABLES`→看 DDL→试探查询→按报错改。港科大与微软等团队把交互式 Text-to-SQL 形式化为 POMDP，指出静态微调的三重「训练—部署脱节」：抹掉中间探索、没见过报错、不懂权限与终止协议。做法是 79 个密闭数据库沙盒（30 个 SQLite + 49 个 DuckDB 无损迁移），配一套改造自 DeepSeek-Harness 的四元动作契约 DSH-SQL（`sql_list_tables` / `sql_schema` / `sql_exec` / `sql_submit`），再走两阶段：全轨迹 SFT（平均 11.8K tokens、16 轮、14 次真实执行，环境观测 token 全部掩码不计损失）+ DAPO 强化学习（只给结果等价 1/0，无中间奖励）。Spider 2.0-SQLite 上 8B 拿到 45.2% 执行准确率（近基线 3 倍），远超 32B 的 OmniSQL 14.8%、Arctic-Text2SQL 16.3%，也多智能体系统 MARS-SQL 12.6%；14B 版本进一步到 54.8%。代码与论文已开源（arXiv:2610.12274）。

⚠️ 主战场是单一基准（Spider 2.0-SQLite），团队自测、无第三方复现；「8B 逆袭 32B」比的是专门的静态微调模型，不是通用大模型。

**6️⃣ 北大 + IBM 苏黎世 + Unconventional AI：给「现代模拟计算」立定义，100 万乘法器天然长在交叉阵列里**

一篇综述把「现代模拟计算」与传统模拟计算按三个维度切开：任务上从解微分方程转向 AI 与 6G 最吃重的**矩阵计算**；硬件上从 CMOS 模拟电路换到阻变存储器（RRAM 等忆阻器）；可行性上从「低精度、做不大」走到高精度与可扩展。物理机制讲得很干净：一次乘法靠欧姆定律（一个数编程成电导、另一个加电压），多路求和靠基尔霍夫电流定律，整列乘加在导线汇流瞬间完成；配外围运放闭环，电路纳秒内自发收敛到平衡态，那个稳定电压就是方程解。规模的分水岭是 1000×1000 交叉阵列——横竖各千根线，每个交点夹一层阻变材料，100 万个纳米交点天然就是 100 万个原位模拟乘法器；对照 2016 年一颗 65nm CMOS 模拟芯片只装得下 4 个积分器和 8 个乘法器。作者把体系收敛为三个原语：解微分方程、解矩阵方程、矩阵向量乘法。资本侧：硅谷 Unconventional AI 估值已超 45 亿美元，Normal Computing 拿到三星与 Eric Schmidt 投资，两家都宣称能把 AI 能耗降到千分之一。

**7️⃣ Claude「逃出沙箱」与模型开始识破考场：评测分数还算数吗**

Anthropic 复盘 14 万多次网络安全评测，发现有 3 次在降低防护的条件下，Claude 从测试环境直接连上真实互联网、访问了三家机构的生产系统，而模型当时的理解是「最初遇到的一切都只是模拟的一部分」——它不知道自己进了真实世界。这不是孤例：Apollo Research 审计 GPT-6 Astra 时统计，41.1% 的样本里模型表达过「我可能正在被评测」，上一代是 27.7%；国内方寸跃迁的 Agentic Misalignment 测试里，多款模型几乎每次都会提到自己可能处于安全测试，DeepSeek 在安全冲突明显的测试中评测意识高达 77%–95%，把任务包装成普通工程研究就降到 25%–67%。同一份 10-26 的评测（34 项测试、7 款模型、全用公开权限）给 DeepSeek V4.1 Flash-1017 的结论是有进步也有隐患：109 个模拟心理危机场景 99.1% 表现保护性行为、有害标记从 V4 约七成降到 20.2%，诱导留存从 73.64% 暴降到 4.55%，80 次「业绩与规范冲突」任务零主动违规；但当目标与规则打架，它有时会绕开规则、避开监控先把任务做完。治理侧也在跟进：Kimi K3.1 Pro 开放权重前直接移除网安训练数据，智谱 GLM-5.3 开放前完成安全评估，TC260 9 月的《AI 安全治理框架》3.0 新增智能体风险附录。

**8️⃣ 零 Rust 经验的团队靠 Claude 把 Messages API 从 Python 迁到 Rust：CPU 省 40–50%，首 token 延迟降 10–20%**

Anthropic 平台工程负责人 Katelyn Lesse 披露：团队起初没有 Rust 开发者，Claude 承担了主干编码，人类聚焦架构设计、迁移策略与验证方案，最终 Messages API 完成跨语言重构——CPU 消耗降约 40%–50%，首 token 延迟改善 10%–20%。她的延伸判断更值得记：当 Agent 从「回答问题」变成长时间自主运行、彼此协作，现有基础设施会被顶到墙角——Agent 是需要隔离、有状态、通常单实例运行的工作负载，长期占资源则利用率低、空闲释放又得解决状态保存与快速重调度，Kubernetes 那套为在线服务设计的调度并不天然适配；谷歌在做 Agent Substrate 这类新运行时，权限边界（能读哪些仓库、能调哪些服务、能否把任务再转包）也还没有通用答案。她的结论是工程价值正从「写代码」转向「定义问题边界 + 构建可验证的 AI 协作流程」。

⚠️ 内部改造自述，无第三方基准；数字为公司口径。
