## 📌 值得看

### 4. ModularRSI：冻结模型权重，只改 Harness 也能让 Agent 持续进化

IQuest Research 联合北航、曼彻斯特大学等发布 ModularRSI：基础模型全程冻结，只让 Agent 依据自身执行经验持续改写模型外围的运行机制（Harness）。做法是把 Harness 拆成观测、工具、上下文等五个模块分别演化，从执行轨迹里找出反复出现的缺陷再改代码。结果 Terminal-Bench 2.0 准确率从 47.57 升至 52.43，改进还能迁移到未参与演化的任务、领域乃至不同基础模型。

原文：[机器之心 · 冻结模型权重，Agent 还能持续进化：ModularRSI 探索 Harness 自我改进](https://www.jiqizhixin.com/articles/2026-09-24-5)（[论文 arXiv:2609.14857](https://arxiv.org/abs/2609.14857)，[代码](https://github.com/IQuestLab/ModularRSI)）

### 5. 小米 MiMo-V3 新架构 HySparse2：长上下文 Prefill 降至 1/5

小米 MiMo 负责人罗福莉 9/23 晚提前披露 MiMo-V3 新架构，核心组件 HySparse2 论文同步公布。针对 Agent 多轮任务长输入痛点：100 万 Token 下 Prefill 计算量降至上代 Hybrid SWA 的约 1/5、KV Cache 降至约 1/4.5。做法是两级 KV 共享，让后半模型复用前半的隐藏状态与缓存，并把块级选择改为 Token 级。
