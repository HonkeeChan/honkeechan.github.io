## 🔥 必读

### 1. [OpenAI 发布 GPT-6.2 Astra 与 Sol：成本再降一档，但首批开发者给出集中差评](https://www.jiqizhixin.com/articles/2026-11-18-2)

OpenAI 双发 GPT-6.2 Astra（复杂项目旗舰）与 GPT-6.2 Sol（日常高效）。官方主打「同样的钱办更多事」：Astra 的 API 输入/输出价格较 GPT-6 Astra 各降 20%、缓存输入降 60%，落到每百万 token **8 / 0.4 / 40 美元**；Sol 沿用上代 **2 / 0.1 / 10 美元**。开放范围扩到 ChatGPT Work 与 Codex 的 Plus / Pro / Enterprise / Edu，Pro 200 首次获得 Ultrafast（先 Sol）。

跑分多为自报：Agents' Last Exam 高 5.2 分而成本不到 1/3，对 Claude Fable 5.2 领先 5.5 分而成本仅 5%；Terminal-Bench-Science 0.1 高 9 个百分点；Harvey 法律任务通过率超 Fable 5.2 两倍、成本约 1/6；GDPval v2 高 6.2 个百分点且输出 token 少 22%。真正拉开身位的是 3D——AA-3D 拿 **1318 Elo 排第一**（较上代 +150，Fable 5.2 为 1271）。但第三方口径也显示 **AA 综合智能指数只是第二**，Coding Agent 指数与上代持平、Sol 反而降 3 分。安全侧两款网络安全能力均达 Preparedness Framework 的 **Critical** 门槛，Astra 的 AI 自我改进达 **High** 门槛。

争议是本期最该记的部分：上线不到 12 小时，X 上差评密集——Theo 称其为「OpenAI 史上最糟糕的模型」，Matt Shumer 说「基本无法使用」，Dan Shipper 团队实测数周后认为写作不如上代、真实项目经常**提前停止**、设计产出高度雷同；而批评者也一致认可其 3D、空间推理与成本效率。成本对照很具体：同一提示词 Sol 花 31 分钟 2.07 美元，Claude Opus 5.5 用 2 小时 46 分花 31.85 美元。⇒ 「能力-成本」与「可用性」要分开读：性价比是真的，但「过度简洁 + 长任务提前停止」在 Agent 场景是硬缺陷。

### 2. [英伟达 FY2027 Q3：营收 1158 亿美元同比 +103%，表外承诺成为新的观察点](https://zhidx.com/p/610862.html)

真正要盯的是三组表外数：采购承诺增至 **3900 亿美元**（上季 2790 亿）；数据中心租赁与云服务承诺超 **1000 亿**（NeoCloud 相关 320 亿，英伟达可拿前期销售收入 + 最低承诺之上的租金分成）；对合作伙伴担保敞口最高 **1180 亿**，其中**对 OpenAI 相关数据中心最高 1050 亿信用支持**——属最高潜在敞口、非已发生支出、截至 10-25 未付款。云行业订单积压从 2 万亿增至 **2.5 万亿**。中国侧：Q3 获许可 Hopper 对华销售 24 亿美元，**已不再交付、Q4 指引未计入**。

治理侧：董事会主席 Harvey Jones 开场即定调——黄仁勋因个人行为不符合公司准则自愿辞职、董事会一致接受，且**「不打算让黄仁勋重新担任 CEO」**；正式 CEO 遴选已启动（内外部并看、克雷斯在内），董事会新设**国家安全与出口管制监督委员会**。同日更早，黄仁勋公开发文称愿回归。→ 这条 CEO 更替线本身仍属定性表述、不单独占档位，本期以「财报」为独立事件记录，因为它给出了可引用的硬数据。

关键数字（自报口径）：**MAI Code 2 四项编程基准综合达 GPT-6.1 Sol 约 98%，测试成本约 40%**；对 Claude Opus 5.5 达约 96% 成绩、成本约 **5%**。**MAI Cyber 2 Flash 在 CyberGym-E2E 成功率 92.3%**，略高于 GPT-6 Astra 的 91.5%，单项成本**不到后者 2%**。MAI Image 2.7 以 **1215 分**登顶图像编辑榜、价格约竞品 1/5。**Decision-1.1 在 AA 决策指数拿 68 分、第 8**，比首款高 6 分，**领先 Jev 1.14、Gemini Decision 1、GPT-6 Luna 决策版**。

### 5. [苹果开源实时视频生成模型 FastFrames：单卡 36 毫秒，加速方法可迁移到别家模型](https://zhidx.com/p/611830.html)

13 亿参数的 FastFrames-S 与 140 亿参数的 FastFrames-L，主打 480P 实时生成。**S 在单张 B200 上延迟 36 毫秒**，质量接近 Causal Forcing++ 而速度约 **7.6 倍**；L 与 Krea-Realtime 效果相当、单卡约 10.6 倍，8×B200 降至 45 毫秒。训练路径不同：S **冻结主干**另训输出/历史两个网络，L 则**对 Wan2.1-14B 蒸馏**。亮点是迁移性——同一套方法让蚂蚁灵波 LingBot 1.3B 提速约 **16 倍**、斯坦福 RealWonder 约 **22 倍**。质量上 S 有明显短板（文字乱码、指令偏差）。仓库 `apple-aiml-research/ml-fastframes` 与 HF 权重已核验，但**许可为非商业科研用途**，不是可商用开源。

### 6. [浙大 + 宇树发布 Movens-5M：500 万条机器人动作、逾 1 万小时](https://www.jiqizhixin.com/articles/2026-11-18-3)

### 7. [Uber 的 MCP Gateway：800 个 MCP Server、5000 个工具，把智能体调用当微服务治理](https://www.infoq.cn/article/FrDlAvNIwkr8ttdvWMCC)

**800+ MCP 服务器、5000+ 工具**。架构是**控制平面 MCP Registry**（工具定义/Schema/所有权/启用状态）与**执行平面 Proxy** 分离，Proxy 把 MCP 请求转 HTTP / gRPC / TChannel 再转回，**现有 API 零改造**即可暴露为工具。AutoCrawler 扫 Protobuf/Thrift IDL 自动生成 MCP Schema + LLM 生成描述，**新工具默认禁用待所属团队审核**，配置变更直接下发无需重启；授权在服务器与工具两级执行，响应做 PII 脱敏。目录膨胀后用**渐进式发现**（搜服务器 → 找工具 → 取单个 Schema）与 Response Projection 按需取字段。社区反馈很一致：这就是 API / GraphQL 网关的老问题，**安全、服务发现、可观测性、治理依然成立**。
