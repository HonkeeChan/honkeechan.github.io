### 1️⃣ OpenDS-World：12 个前沿模型实测，最强的 GPT-6 Astra 也只有 39%

港科大（广州）、复旦、华盛顿大学、帝国理工、斯坦福等提出 OpenDS 任务范式与 OpenDS-World 基准：200 道题覆盖 4 种模态、42 种资源格式、7 类证据访问需求——证据可能藏在视频某一帧、论文图表、需下载的数据文件，或藏在需要调地区/调时间的交互式页面里。给 12 个前沿模型同一套搜索、浏览器与视频工具，每题限 1 小时、100 次工具调用，最强 GPT-6 Astra 准确率仅 **39%**，Claude Opus 5.5 38.0%、Gemini 3.8 Flash 36.5%，其余均不足 35%。最值得记的反差：每题人工标注来源平均只有 3.94 条，模型一次搜索却调用几十到近百次工具；GPT-6 Astra 的失败调用只占 6.34%，却消耗了 42.57% 的工具执行时间。结论是 Agent 在真实开放网络上的瓶颈不在「会不会搜」，而在**失败重试的代价**。论文 arXiv 2610.30181，代码与数据集已开源。

### 2️⃣ dsh-Go：把 DeepSeek Harness 装进口袋，3 小时破千星

DeepSeek Harness 插件 dsh-TUI 的作者 ccch1mneyyy 公测开源项目 **dsh-Go**——为 DSH 设计的移动端应用。发布 3 小时 GitHub 破 1k 星，发稿时 1.7k 星、安装包下载 6000 多次（今日复核仓库已 **2,417 星**）。能力包括：连接主机 DSH 实时同步消息与任务进度；在手机上本机运行一套打包好的 Ubuntu 24.04 + Node.js + DSH（PRoot，免 Root、不必另装 Termux）；内置插件市场（电脑与移动端均可装）；手机操控（读屏、闹钟、导航、点按输入，涉及账号密码的高危操作默认全关）；会话可扫码分享、支持链接/图片/文件/文字四种导出。智东西实测：连续对话不崩、能直接在手机上做出可玩的网页小游戏，短板是偶发延迟、连接断开与会话同步中断。意义在于——官方还没覆盖的移动端与远程操控，社区先做出来了，DSH 生态正从单机工具长成工具链。

### 6️⃣ 华为袁远：智算中心 70% 算力没形成有效价值，数据开发率仅 28.4%

### 7️⃣ Addy Osmani：别再「过度提示」Claude——系统提示删掉 80% 也没有性能下降

Anthropic Claude Code 团队成员、谷歌前工程总监 Addy Osmani 主张「别再过度提示」：用一条提示写清要做什么 + 如何自检，然后放手；推理强度从 `/effort medium` 起步。硬证据是 Claude Code 曾针对 Opus 5、Fable 5 等模型**删掉 80% 以上系统提示词，编程评测没有可测量的下降**。配套做法：`/goal` 让另一个模型每轮验收、阶段 checkpoint 汇报、`/doctor prompt-audit` 找出为旧模型写的规则、子智能体数量与任务规模匹配（小任务多开会更慢更贵）、长任务用云端会话、先把单会话跑通再并行。提醒：自动模式仍需核验——让它展示执行过的命令与输出。
