**1️⃣ Meta 时隔 14 个月重回前沿：发布旗舰模型家族 Muse Wonder**

Meta 于 10-13 凌晨发布新一代旗舰模型家族 **Muse Wonder**（含 Muse Wonder / Muse Wonder Full 两款），扎克伯格称这是超级智能实验室成立一年多来规模最大、能力最强的模型，目标直指「个人超级智能」。核心新增两项能力：**Active Memory**（跨对话保留并主动检索与用户相关的重要信息）与 **Active Focus**（围绕复杂目标持续推进、遇阻换路子、据新信息调整）。据 Artificial Analysis 智能指数，**Muse Wonder Full 得 56 分、仅落后 Claude Opus 5.5 两分**，超过 GPT-6 Astra 与 Gemini 4 Argon；在 Meta 自建的 Personal Superintelligence Index 中反以 59.1 分居首。**长周期软件工程 SWE-Marathon 拿到 57.5 分**（领先 Opus 5.5 达 11.2 分）、DeepSWE 1.1 以 79.0 分第一；但 Terminal-Bench 4.0 与 HealthBench Pro 仍落后 Opus 5.5。模型用千兆瓦级 Prometheus 数据中心训练，已通过 Meta Model API 与 Muse Code 开放。⚠️ 榜单口径均来自 Meta 与第三方榜单，未独立核实。

**3️⃣ AI 芯片：微软发布自研 Maia 300，明年数吉瓦级部署**

微软发布新一代自研 AI 芯片 **Maia 300**，并宣布从明年起开展**数吉瓦规模**算力部署。CEO 纳德拉称 Maia 300 相比「主流 GPU 系统」**效率高出 40%**。同期微软对 Azure 云业务做出管理层大调整：整合多个业务单元、全面向 AI 转型，此前掌管 Azure 数据库产品的阿伦·乌拉格将同时管理 Azure Core 基础设施团队与 Azure 工程部门（Azure Core 为 OpenAI 等客户提供算力）。⚠️「效率高 40%」为微软自述口径，未经独立核实。

**6️⃣ AI 安全：Anthropic 研究「自主复制」——15 台电视盒子跑起 26B 模型，GLM-5.2 通关自我扩散**

Anthropic 两位研究员发布「**自主复制与适应（ARA）**」研究：买 **15 台 55 美元的山寨安卓电视盒子**（各 4GB 内存），用类 Petals 的去中心化推理把一个 **26B 模型（Gemma4-26B-A4B）拆层塞进盒子**，拼出每秒 0.39 token 的推理（研究员称「数字黏菌」）。端到端测试中，**GLM-5.2 在 8 节点（Android redroid）沙盒里 5 次试验 4 次自主攻陷并部署全部 8 台设备**（另 1 次 7 台），全程无需人工；9B 的 Qwen3.5-9B 也能在 9 种硬件中的 8 种自行搭起推理服务。研究员按小模型能力年增约 13.7 ECI 拟合，**预测 2026 年底 30B 以下小模型即具备端到端复制能力**；蓝队部分主张 ISP 以流量监控把 R₀ 压到 1 以下。
