### 2. 斯坦福 & Together AI 提出文本生成「第三范式」：先写提纲，最快 31 倍

斯坦福大学与 Together AI 提出既非自回归、也非扩散的**第三种文本生成范式 Next-Concept Modeling（NCM）**：借鉴 NeurIPS 2024 最佳论文 VAR 的「下一尺度预测」，让模型**先并行写出几句「概念大纲」，再逐层并行填充细节**还原成完整文字，正面叫板主流的 Next-Token 建模。训练分两阶段：先训多尺度残差 VQ-VAE（把文本转成多层离散编码，训练时随机截去细层以防粗层「偷懒」），再冻结并训 Transformer 预测下一层。效果（单块 H100 SXM 80GB）：LM1B 无条件生成比强扩散基线**快约 21 倍**且困惑度更好；OpenWebText 约 **10 倍**；XSum 摘要在 ROUGE-L 相当下约 **31 倍**；训练 token 仅为对比对象的 1/4.9 与 1/4（DUO/MDLM 在 OpenWebText 需跑 100 万步、逾 5000 亿 token）。数独困难题（30 线索）完整解出率 **86.1%**，高于 FMLM+ 的 81.3%，生成器调用 12 次 vs 16 次。⚠️ 主体实验约 1 亿参数、扩展至 7.25 亿参数，**规模化与长文本表现待验证**。arXiv 2610.14162，代码开源（HazyResearch）。

### 3. EinsiaAI 发布 EmbodiedEvo：自进化 Coding Agent 登顶具身基准 RoboDojo

Einsia AI 旗下 Navers Lab 提出 **EmbodiedEvo**：让 Coding Agent 用 Python 程序控制机器人，每个任务仅用一个 Playground 场景交互，积累两类经验——**Skills**（把「怎么做」写成代码，如对齐、抓取、抬升并检查夹持）与 **Lessons**（把「何时做、哪里易错」记下，如先看完演示再动）。探索后把经验**冻结成 harness 交给新 Agent**，在未见场景评估，**无需更新模型权重**。控制接口只有四个原语（get_instruction / get_observation / step / reset），不预置「抓取成功」等高级技能。在被称为「具身珠峰」的 RoboDojo 评测中取得 **45.08 平均分、38.95% 成功率**，超过所有 VLA/WAM、Agent、Agent+VLA 方法。自进化让同配置成功率从 **13.36% 提升到 35.08%**；原本 0 成功的堆叠与井字棋升至 100%、模仿分拣 0→80%；但插管/插钥匙仍为 0 成功率（精细接触未解决）。继承 Astra 经验后，较弱模型 GPT-5.6-Sol 成功率也提升。arXiv 2610.18867，代码与项目主页开源。

原文：[机器之心 · 具身智能迎来范式跃迁！EinsiaAI 发布 EmbodiedEvo](https://www.jiqizhixin.com/articles/2026-10-15-10)

### 5. Linux 之父用 Claude Code 写内核补丁：8 线程吞吐约 3 倍，顺带挖出十年旧 Bug

Linus 的官方内核仓库出现新分支 **`noref-filemap-read-with-llm`**，他在补丁说明中承认核心代码、测试用例、改动审查与文档草稿均在其指导下由 **Claude Code** 完成。改动针对内存管理老问题：多线程小块读同一文件时反复修改 folio 引用计数，引发 `lock cmpxchg`/`lock decl` 造成的缓存行颠簸（其测试机上 8 线程小读时该瓶颈占 Load HITMs 开销 **99.92%**）。补丁借助 **RCU 延迟归还**被移除的缓存，减少共享引用计数争抢：**8 线程吞吐约 3 倍**（约 1000 万→3300 万/秒）、单线程约 +10%（Core i7-8565U/ext4）。次日又冒出一个 **assoc-array-fixes** 分支：借大模型拆分晦涩函数并用用户态测试，除开发者 Nils Ollrogge 报告的 Bug 外又找出 3 个，**全部可追溯到 2013 年的首次提交**。
