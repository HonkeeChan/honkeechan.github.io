### 1. OpenAI 发布 GPT-6 Astra：能直接操作电脑的 Agent 模型

面向编程、GUI 交互与专业工作流，已向 ChatGPT 付费档、API、Azure、Bedrock 开放。能端到端操作软件：填表单、改 CRM、排查屏幕问题——**OSWorld 2.0 得 72.6%**（前代 GPT-5.6 Sol 为 65.7%）；**Terminal-Bench 4.0 为 57.9%**、**DeepSWE v1.1 为 74.1%**。Codex 首发实验性「跨窗口笔记」，长任务可回查早期需求；**100 万 token 上下文在 512K–1M 区间得 96.3%**，幻觉率由 12.2% 降到 4.2%。它也是首个被判为「关键网络安全能力」级的模型，测试中发现并利用 2 个未知漏洞。

原文：[InfoQ · OpenAI 发布适用于编程和计算机应用的 GPT-6 Astra](https://www.infoq.cn/article/IfxYoy1PPkFQUpjWVBVr)

### 2. 飞书 8.0 for Agent + 豆包工作伙伴：团队 Agent 正式进群

Agent 首次能以「人」的方式进群：被拉进群聊、多个 Agent 互相协作，并拥有独立身份、权限与团队共享记忆，按职责主动干活。CLI 开放的功能点从 3 月的 **247 个增至 767 个**；权限沿用员工体系（员工看不到的 Agent 也看不到），企业可按人设 Token 上限。梁汝波称 Agent、模型、协作环境必须融合。

### 4. Meta 新研究：字节级蒸馏突破 Token 天花板

Meta FAIR 与华盛顿大学把蒸馏单位从 Token 换成 byte：候选空间从 12.8 万 Token 缩到 256 个字节值，存储压力大降。以 Llama 3-8B 为教师，Token 蒸馏准确率上限 48.4%，新方法 End-Of-Token 达 **52.4%**、高 4 个百分点。

原文：[量子位 · Meta新研究：字节模型蒸馏后，天花板破了](https://www.qbitai.com/2026/09/489337.html)

### 5. 联发科天玑 9600 Pro 发布：2nm + AI 原生架构

原文：[智东西 · 联发科2nm旗舰芯天玑9600 Pro发布](https://zhidx.com/p/594035.html)
