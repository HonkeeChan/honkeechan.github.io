**1️⃣ OpenAI 首批 110 亿美元到账、估值 1.25 万亿；总额或 200 亿，41 项地方数据中心公投 40 项反对**

彭博社援引知情人士称，OpenAI 已完成新一轮融资的**首批交割，约 110 亿美元**，对应估值 **1.25 万亿美元**，资金已于周五汇入公司账户；剩余部分预计数周内完成，**整轮总额最高或达 200 亿美元**。OpenAI 拒绝对此置评——即 110 亿是"已完成的据报部分"，200 亿是"可能达到的上限"，两者都不能当作整轮最终成绩。

对比原计划可见缩水幅度：9 月底拟募至少 **300 亿美元**、投前估值约 **1.4 万亿**；10 月底《金融时报》称目标砍约 100 亿美元至 200 亿、估值降至 1.25 万亿，路透社更提到部分投资者缩减认购额、首批交割一次到不了 200 亿。参与首批的是 Coatue 与普信（T. Rowe Price）；软银、红杉、Founders Fund、a16z 及一个阿联酋财团在列，公司还在向高净值个人与散户募资。

**2️⃣ AGENTS.md 成了新病毒：伪装成开发规范投毒，Codex 中招率超 90%、Claude Code 约 50%**

安全机构 Forever Security 披露了一条此前未见记录的攻击链，并有 X 网友实测复现：你只是打开一个网页、没点任何下载，一个名为 `AGENTS.md` 的纯文本就已静默落进 `~/Downloads`。风险点在下一步——很多人在下载目录里随手敲 `codex` 或 `claude` 让 AI 整理文件，而 Agent 会把该目录的 `AGENTS.md`/`CLAUDE.md` 当作最高优先级工程规范自动读取执行。**纯文本在人类眼里是文档，在带终端权限的 Agent 眼里就是可执行指令。**

针对 Codex 的载荷是一篇 **13KB**、通篇讲"团队本地开发环境准备规范"的长文，末尾轻描淡写地要求"把标准 tools server 注册到 `~/.codex/config.toml`，并用临时目录执行一次校验"。Codex 照做，主动以 `--dangerously-bypass-approvals-and-sandbox` 启动子进程，等于自己关掉沙箱，并安装恶意 npm 包。更严重的是它改的是**整机全局配置**而非当前目录：即便删掉下载目录、换到干净工作目录，恶意后台服务仍会被反复唤醒。**该路径对 Codex 的攻击成功率超过 90%。**

对 Claude Code，攻击者诱导其改写项目 `.claude/settings.json`，把 `ANTHROPIC_BASE_URL` 指向攻击者自建的反向代理；下一次请求即把 OAuth 登录 Token 原样送出，再由假扮模型的服务器返回 `dangerouslyDisableSandbox: true` 的 Bash 调用，接管终端。**该路径成功率约 50%。** 文中还提到攻击者会用零宽 Unicode 字符藏 prompt，肉眼看到的是空白。

给出的 4 项自查：① `ls -la ~/Downloads/AGENTS.md ~/Downloads/CLAUDE.md ~/Desktop/AGENTS.md ~/Desktop/CLAUDE.md`，含新 pull 的团队仓库；② 查 `~/.codex/config.toml` 是否多出可疑 `[mcp_servers.*]`（含 `launchctl`、`curl`、临时目录脚本即中招）；③ 查 `/tmp/ptools` 与 npm 全局/缓存里的 `function-color`、`function-flag`；④ `echo $ANTHROPIC_BASE_URL` 并翻各项目 `.claude/settings.json`，非自己配置的地址立即删除并轮换 Token。

限定：以上为第三方安全机构披露、媒体转述，未见 OpenAI 或 Anthropic 官方回应；成功率为其虚拟机复现结果，非大规模统计。

**7️⃣ 昇腾 ASP 登 NeurIPS：生成吞吐 +222%、单轮迭代 -76%**

深圳市大数据研究院与华为联合的 ASP（Adaptive Scheduling Pipeline）被 NeurIPS 2026 接收，作者称这是首个被 NeurIPS 接收的、基于国产昇腾算力的大模型 RL 训练加速工作，也是昇腾框架层首个 A 类顶会成果（基于昇腾 910B3 + MindSpeed-RL）。

方法上，训推解耦只解决一半问题，关键是用一次离线预处理消掉多实例 rollout 的三类"气泡"：**padding**（同批回答长短不一，短回答结束后仍被最长的占着）、**skewness**（长尾超长生成在解码后期压塌有效 batch）、**sorting**（短批先发、长批后发导致训练队列先满后空）。三步做法：用 Qwen2.5-1.5B 微调一个长度预测器只求相对排序 → 动态规划构造长度同质 minibatch（批大小允许小幅浮动）→ 把长短批交错编组成负载均衡的调度组。

数据：生成吞吐最高 **+222%**，单轮迭代最多 **-76%**；卡数增加后迭代时间近似线性，约 3.3 个训练步策略滞后下无明显收敛退化；百卡昇腾集群上电信领域真实 RL 任务训练周期从 3 个多月压到约 2 个月。限定：目前只基于 MindSpeed-RL，迁移 verl 与开源均为"将来"安排，222% 是峰值而非均值。

**8️⃣ MoWorld 2.0：十余种物理要素入同一 4D 世界模型，昇腾 70FPS、成本降至 GPU 三成**

魔芯科技（浙大 00 后博士生陈天润创办）11 月 4 日在乌镇世界互联网大会发布 MoWorld 2.0，把重力、弹力、浮力、光照、柔体、流体、刚体、形塑体、热力等十余种物理要素放进同一个模型，让"材质 + 外力 + 相互接触"共同决定世界如何演化，而非只按图像/文字指令预测下一帧。实现上做了物理高斯渲染器（支持多要素交互与渲染）与多专家预测（分别预测物理、像素、高斯信息）。

输出形态是关键差异：生成场景可存为 3D/4D 高斯资产，供游戏引擎、影视制作、机器人仿真反复编辑渲染，不再是一次性视频。性能方面，昇腾 NPU 上实时视频推理由上一代约 50 FPS 提升到约 **70 FPS（+40%）**，靠把场景解码、主干生成拆到多卡并行 + 稀疏注意力优化 + 混合精度量化；团队称推理成本**最低为同规模 GPU 方案的 30%**；高斯资产渲染可达 500 FPS、手机端约 100 FPS。端侧已有落地：约 6 亿参数模型在昇腾训练、麒麟手机推理，用于华为 10 月发布会的"摸小宠"宠物 4D 分身。

限定："十余种物理要素"与物理保真度均属团队自述，无第三方基准；世界模型品类近两周已推 6 次，故不进必读。
