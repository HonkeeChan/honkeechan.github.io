## 🔥 必读

**1️⃣ 跨维智能 UNITAS：全球首个机器人任务原生 3D 世界模型，1.7B 参数横扫操作榜单**

跨维智能（DexForce）发布 UNITAS（A 3D-Native World Action Model for Embodied Manipulation），主张具身智能缺一个像「文本之于大模型」那样的原生统一空间——答案是三维物理世界本身。它把机器人「看见什么（观察）、自己怎么动（动作）、世界因此怎么变（场景动力学）」统一放进同一个三维点表示空间：观察对应三维位置，动作是夹爪上三维点随时间变化的轨迹，环境变化是场景点在同一坐标系下的轨迹；主干模型直接处理三维 Token，而不是从二维画面里反推三维。成绩：仅 1.7B 参数，LIBERO 平均成功率 **99.8%**、LIBERO-Plus **89.1%**、RoboTwin 2.0 双臂 Clean **92.94%** / Randomized **93.04%**，超越 6B 的 Fast-WAM、8B 的 Motus 以及 π0.5、LingBot-VA、PointWorld，真实机器人任务平均成功率 **85%**。关键发现：加入 Scene Flow 监督后，动作策略本身还在继续提升——「理解世界会发生什么」反过来帮它「知道自己该怎么做」。论文 arXiv 2610.12099，代码已在 GitHub 开源。⚠️ 为论文/厂商自测口径，尚无第三方复现。
原文：[机器之心 · 全球首个机器人任务原生3D世界模型：跨维UNITAS](https://www.jiqizhixin.com/articles/2026-10-12-5)

**2️⃣ 华为 Memento 3 用「代码即模型」通关 ARC-AGI-3 全部 25 款游戏，操作比人类少 56%**

华为诺亚方舟实验室联合 UCL 等提出 Memento 3，在 ARC-AGI-3 公开集 25 款游戏、183 个关卡上全部通关，RHAE（相对人类行动效率）满分 **100**；总操作 **7518 次**，比人类完成同套关卡所需的 17135 次少约 **56%**，也比此前最强 baseline（独立开发者 Sergey Rodionov 的 baseline1，99 分、8347 次）更省 829 次。底模是 Claude Opus 5，全程**不改权重、不做游戏微调**，靠的是「Code as Model」：边玩边维护一本 Markdown 规则手册（Rulebook）＋一套能运行的 Python 可执行世界模型，先在自己搭的模拟器里推演再行动；发现规则写错就推翻重来（例：原以为图案按进入方向镜像翻转，实测是顺时针旋转 90 度），并逐格比对 64×64 画面校验——同一份规则手册迭代了 11 个版本，团队甚至用 Git 管理版本。对照实验：去掉规则手册、只留代码世界模型，操作数从 617 升到 677（「攻略」省约 9%）。转到 Atari 的 Pong，AI 摸清策略后不再调用大模型，连赢三局 21:0。论文题为 Model-Based Recursive Self-Improvement。⚠️ 单源（量子位）报道、团队自测口径。
原文：[量子位 · 华为AI靠RSI通关25款游戏！操作次数比人类少56%](https://www.qbitai.com/2026/10/502654.html)

**3️⃣ Claude 上线 Managed Agents 动态工作流：单次最多 1000 个 Agent 自己组队干活**

Anthropic 于 10 月 10 日为 Claude 开启两项 Agent 能力公测：① **Managed Agents 动态工作流**——主 Agent 接到任务后可自己编写分工程序、安排其他 Agent 分阶段完成再汇总，单次工作流累计最多启动 **1000 个 Agent**（当前同时工作线程上限 64），接入时把 multiagent 配置的 type 设为 `multiagent_20261001`。官方示例是筛 300 份合同中的控制权变更条款，流程规定第二轮由另一个 Agent 复查全部合同、漏检的返工后再复核。② **Claude Code Projects 扩大公测**（原等待名单的 Pro/Max 用户已可开通）：围绕一个项目持续提需求、多线程云端并行推进，并积累项目记忆（需求变更、已做决定、踩过的坑都可留档供后续线程读取）。对比数据：在 11.6 万行代码里预埋 70 个 Bug，单 Agent 跑三次最好只揪出 27 个（不足四成），动态工作流三次每次都查出 **66 个**（九成以上）。⚠️ 官方未披露 Bug 测试的具体分工，不能据此断定其流程与合同审查示例一致。
原文：[新智元 · Claude自己组队查Bug！11.6万行代码揪出66个](https://aiera.com.cn/asi-post.html?id=118129)
